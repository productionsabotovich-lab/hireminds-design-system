# Изменения

Версии — [semver](https://semver.org/lang/ru/). Пока система в `0.x`: **minor** — новый компонент, проп, вариант
или токен, а также изменение, после которого экраны платформы нужно править; **patch** — исправление без изменения API
(стили, превью, README). Каждый PR, который меняет пакет (`components/`, `tokens/`, `styles/`, `fonts/`), поднимает
версию в `package.json` и добавляет раздел сюда; после влития в `main` тег `vX.Y.Z` и релиз создаются автоматически.
Платформа ставит пакет по тегу: `github:productionsabotovich-lab/hireminds-design-system#vX.Y.Z`.

Раздел: `## X.Y.Z — ГГГГ-ММ-ДД`, внутри — «Добавлено», «Изменено», «Исправлено» и «Что обновить в платформе».

## 0.9.0 — 2026-10-26

Подсказка и ссылка-иконка «назад» по утверждённым макетам 2b (HIR-59, заявка 2 из 13). Новых токенов нет.

### Добавлено
- `Tooltip` — `text`, `children`, `focusable`, `describe`: подсказка по наведению и фокусу; закрытие по Esc (дальше
  событие не идёт), потере фокуса и уходу курсора с элемента и с подсказки через 120мс (WCAG 1.4.13); пузырь
  `ink` / `surface`; у края экрана сдвиг внутрь, у верхнего — под элементом; значок — `role="img"` с именем,
  ссылка — `aria-describedby`. Заменяет `Tip` набора макетов.
- `BackLink` `variant="icon"` — квадрат 28px со стрелкой «←», подпись — строка `children` (тип требует строку) —
  в `aria-label` и в `Tooltip` без повторного `aria-describedby`. Заменяет `IconLink` набора. У всех вариантов `BackLink` — кольцо фокуса `accent`.

### Исправлено (ревью 0.8.0)
- `Pill`: ореол точки с пульсом — основной тон 35% через `color-mix` в sRGB: виден на заливке `-soft` (soft-токен с
  ней сливался) и без бирюзового артефакта Chrome; проверено снимком кадров анимации на трёх тонах.
- `RouteSteps`: тени — `color-mix(in srgb, var(--ink) 8%, transparent)`; пересчёт и при уменьшении числа шагов, и при
  изменении ширины строки шагов; рамка — `isolation: isolate`.
- `components/index.ts` — экспорты по алфавиту.

### Что обновить в платформе
- Тег `#v0.9.0`.
- «←» в шапке экранов — `<BackLink variant="icon" href={…}>Назад к PIL-15</BackLink>`; значки без подписи —
  `<Tooltip text="…">`.

## 0.8.0 — 2026-10-26

Примитивы по утверждённым макетам 2b (HIR-58, заявка 1 из 13). Новых токенов нет.

### Добавлено
- `Icon`: 17 имён по Lucide 0.460, штрих 1,8 — `session` (activity), `decision` (split), `tracker` (square-kanban),
  `workflow`, `hard-drive`, `box`, `milestone`, `circle-dot`, `tags`, `clock`, `ellipsis`, `search`, `globe`, `brain`,
  `reply`, `queue` (list-end: в Lucide нет `queue`), `alert` (circle-alert).
- `RouteSteps`: при горизонтальной прокрутке — лёгкая тень у края, за которым есть ещё шаги; пропадает у края.

### Изменено
- `Icon` `epic` — стопка слоёв (Lucide `layers`) вместо флажка.
- `Dot` status и kicker: внешний отступ 3px под ореол — ореол не обрезается `overflow: hidden`, ячейкой сетки и
  строкой с многоточием. Точка стала занимать на 6px больше по каждой оси.

### Исправлено
- `Pill`: ореол точки — `accent-soft` / `warn-soft` / `danger-soft` вместо oklch с прозрачностью (Chrome рисовал его
  бирюзовым в анимированном слое).

### Что обновить в платформе
- Тег `#v0.8.0`.
- Рядом с `Dot` status убрать свои отступы под ореол (если были) и `StatusDot` из набора макетов — `Dot` справляется сам.

## 0.7.0 — 2026-10-24

Мелкие доработки после ревью `CommentForm` и `Switcher` (HIR-52). Новых токенов нет.

### Добавлено
- `Textarea`: `readOnly` — текст виден, фокус остаётся.
- `Switcher`: `panelId` — у вкладок `aria-controls` и id `switcherTabId(panelId, tab.id)`; функция `switcherTabId`
  для `aria-labelledby` панели. `ActivityFeed` связывает свою панель с вкладками.

### Изменено
- `CommentForm`: во время отправки поле `readOnly`, а не `disabled` — фокус остаётся в поле. Подпись `hint` по
  умолчанию — «Комментарий попадает в журнал задачи», без названия трекера.
- README `Switcher`: когда это вкладки (`tabpanel`), когда переключатель режима без панели (`radiogroup` /
  `aria-pressed`, не `Switcher`). README `DescriptionList`: ширину задаёт родитель.

### Что обновить в платформе
- Тег `#v0.7.0`.
- `CommentForm` в карточке задачи — передать `hint="Комментарий попадает в журнал и в тред Linear"` явно.

## 0.6.2 — 2026-10-24

Долги доступности и раскладки в компонентах, которые стоят в макетах 2b. API не меняется (кроме нового необязательного
`label` у `Switcher`).

### Исправлено
- `Switcher`: клавиатура по шаблону WAI-ARIA tabs — в порядке Tab только активная вкладка, ← / → и Home / End — по
  вкладкам; видимый фокус — кольцо `accent` (раньше фокуса не было); новый `label` → `aria-label` у `tablist`;
  переходы отключаются при `prefers-reduced-motion`. `ActivityFeed` передаёт `label="Вид журнала"`. Кольцо — внутри
  вкладки (на треке `inset` `accent` даёт 2.95:1); клавиши с модификаторами не перехватываются.
- `CodeChip` (ссылка) и `ResultList` (сворачиваемый заголовок): кольцо фокуса `accent` вместо `ink` — как во всей системе.
- `DescriptionList` `stack`: колонки перестраиваются по ширине самого списка (container query), а не экрана; список
  обёрнут в `div` шириной 100% родителя (контейнер не берёт ширину от содержимого).
- `npm run check`: превью без записанного скриншота — ошибка, а не `ok` (snap-Chromium со своим `/tmp` или без прав
  на запись молча не пишет файл).

### Что обновить в платформе
- Тег `#v0.6.2`; правок в коде экранов нет.

## 0.6.0 — 2026-10-24

Форма комментария к задаче по макету «Карточка задачи» (HIR-48). Новых токенов нет.

### Добавлено
- `CommentForm` — `id`, `value`, `onChange`, `placeholder`, `mentions`, `onSubmit(text)`, `loading`, `error`, `label`, `hint`:
  `Textarea` с подсказкой упоминаний на «@» в позиции курсора, подпись и кнопка `ink` «Отправить».
  Упоминания — `CommentMention { name, kind: "role" | "person", caption?, image? }`: роли из workflow и специалисты,
  с аватаром и подписью «роль» / «специалист»; фильтр по началу слова имени или подписи. Без `mentions` — обычное поле.
  Клавиатура: ↓ / ↑, Enter или Tab, Esc; Ctrl/⌘+Enter — отправить; во время ввода через IME клавиши не перехватываются.
  Поле — `combobox`, список — `listbox`. `onSubmit` может вернуть `Promise`: текст очищается после успеха, при ошибке остаётся.
- `Textarea`: необязательные `onKeyDown` и `combobox: { listId, expanded, activeId? }`; без них поле — как раньше.

### Что обновить в платформе
- Тег `#v0.6.0`.
- Карточка задачи под журналом — `<CommentForm mentions={роли workflow и специалисты проекта} loading={…} error={…} onSubmit={(text) => …} />`.

## 0.4.0 — 2026-10-24

Журнал задачи и лента «Шаги» сессии по макету «Карточка задачи» (HIR-41). Новых токенов нет.
