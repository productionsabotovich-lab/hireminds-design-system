# Изменения

Версии — [semver](https://semver.org/lang/ru/). Пока система в `0.x`: **minor** — новый компонент, проп, вариант
или токен, а также изменение, после которого экраны платформы нужно править; **patch** — исправление без изменения API
(стили, превью, README). Каждый PR, который меняет пакет (`components/`, `tokens/`, `styles/`, `fonts/`), поднимает
версию в `package.json` и добавляет раздел сюда; после влития в `main` тег `vX.Y.Z` и релиз создаются автоматически.
Платформа ставит пакет по тегу: `github:productionsabotovich-lab/hireminds-design-system#vX.Y.Z`.

Раздел: `## X.Y.Z — ГГГГ-ММ-ДД`, внутри — «Добавлено», «Изменено», «Исправлено» и «Что обновить в платформе».

## 0.6.2 — 2026-10-24

Долги доступности и раскладки в компонентах, которые стоят в макетах 2b. API не меняется (кроме нового необязательного
`label` у `Switcher`).

### Исправлено
- `Switcher`: клавиатура по шаблону WAI-ARIA tabs — в порядке Tab только активная вкладка, ← / → и Home / End — по
  вкладкам; видимый фокус — кольцо `accent` (раньше фокуса не было); новый `label` → `aria-label` у `tablist`;
  переходы отключаются при `prefers-reduced-motion`. `ActivityFeed` передаёт `label="Вид журнала"`. Кольцо — внутри
  вкладки (на треке `inset` `accent` даёт 2.95:1); клавиши с модификаторами не перехватываются.
- `CodeChip` (ссылка) и `ResultList` (сворачиваемый заголовок): кольцо фокуса `accent` вместо `ink` — как во всей системе.
- `DescriptionList` `stack`: колонки перестраиваются по ширине самого списка (container query), а не экрана; список
  обёрнут в `div` шириной 100% родителя (контейнер не берёт ширину от содержимого).
- `npm run check`: превью без записанного скриншота — ошибка, а не `ok` (snap-Chromium со своим `/tmp` или без прав
  на запись молча не пишет файл).

### Что обновить в платформе
- Тег `#v0.6.2`; правок в коде экранов нет.

## 0.6.1 — 2026-10-24

Правки по сверке конвейера (HIR-50). API компонентов не меняется.

### Добавлено
- Токены `accent-deep` `oklch(0.52 0.17 150)` и `accent-deep-2` `oklch(0.46 0.15 150)` — заливка под белым текстом
  в семье `accent`; сейчас только градиент `UserAvatar`.

### Исправлено
- `UserAvatar` `color="accent"`: градиент `accent-deep` → `accent-deep-2` вместо `accent` → бирюзовый
  `oklch(0.55 0.18 200)`. Бирюзу запрещает брендбук; белые инициалы были 3.3–4.0:1, теперь 5.0–6.5:1 (AA).
  Аватар текущего пользователя стал темнее; `accent` в остальных местах не меняется.
- `tokens.json`: `usage` у `space-9` — по паттернам: верхний паддинг страницы, `MainPanel`, auth-экраны; `StageHeader`
  использует `space-5` (записано в его README). `tokens.css` не меняется: `usage` в него не выводится.
- Паттерны `TopbarSteps` и `Timeline`: цифра текущего шага — `accent-ink` на `accent-soft` с рамкой `accent` (10:1)
  вместо белой на `accent` (3.3:1).

### Что обновить в платформе
- Тег `#v0.5.1`; правок в коде экранов нет.
## 0.6.0 — 2026-10-24

Форма комментария к задаче по макету «Карточка задачи» (HIR-48). Новых токенов нет.

### Добавлено
- `CommentForm` — `id`, `value`, `onChange`, `placeholder`, `mentions`, `onSubmit(text)`, `loading`, `error`, `label`, `hint`:
  `Textarea` с подсказкой упоминаний на «@» в позиции курсора, подпись и кнопка `ink` «Отправить».
  Упоминания — `CommentMention { name, kind: "role" | "person", caption?, image? }`: роли из workflow и специалисты,
  с аватаром и подписью «роль» / «специалист»; фильтр по началу слова имени или подписи. Без `mentions` — обычное поле.
  Клавиатура: ↓ / ↑, Enter или Tab, Esc; Ctrl/⌘+Enter — отправить; во время ввода через IME клавиши не перехватываются.
  Поле — `combobox`, список — `listbox`. `onSubmit` может вернуть `Promise`: текст очищается после успеха, при ошибке остаётся.
- `Textarea`: необязательные `onKeyDown` и `combobox: { listId, expanded, activeId? }`; без них поле — как раньше.

### Что обновить в платформе
- Тег `#v0.6.0`.
- Карточка задачи под журналом — `<CommentForm mentions={роли workflow и специалисты проекта} loading={…} error={…} onSubmit={(text) => …} />`.

## 0.4.0 — 2026-10-24

Журнал задачи и лента «Шаги» сессии по макету «Карточка задачи» (HIR-41). Новых токенов нет.

### Добавлено
- `ActivityEvent` — запись журнала: маркер `Dot` по тону вида или аватар роли (`message`), «кто — что» (`actor`,
  `children`), `detail` одной строкой, `quote`, `files` (`CodeChip`), `pill`, время. `kind="phase"` — глава с `Pill`
  `ink`. Виды: `phase`, `session`, `message`, `pr`, `decision`, `return`, `note`, `error`, `reminder`, `system`; шаги `files`,
  `check`, `push`, `ask`. Экспортирует `ACTIVITY_TONE` — тон по умолчанию для вида.
  README — таблица «событие журнала → вид и тон → в „Сообщениях“».
- `ActivityFeed` — `variant: task | session`, `events`, `view: messages | all` (+ `onViewChange`), `now`, `loading`,
  `emptyText`, `title`, `updatedAt`. `task`: дни «Сегодня» / «Вчера» / дата, `Switcher`, без шагов; `session`: без
  дней, все виды, `UpdatedAt`.

### Исправлено
- `CodeChip`: `overflow-wrap: anywhere` вместо `word-break: break-all` — короткий идентификатор («S-118») переносится
  целиком, по символам рвётся только значение длиннее строки.

### Что обновить в платформе
- Тег `#v0.4.0`.
- Журнал карточки задачи — `<ActivityFeed events={…} now={…} />` вместо локальных `ActivityItem` и `LiveActivity`;
  лента «Шаги» экрана сессии — `<ActivityFeed variant="session" updatedAt={…} />`.

## 0.3.0 — 2026-10-24

Расширения существующих компонентов по макету «Карточка задачи» (HIR-49). Новых компонентов и токенов нет.

### Добавлено
- `Pill`: `tone="ink"` — фон `ink`, белый текст; только название фазы в строке перехода журнала. В README — таблица
  «состояние → тон».
- `DescriptionList`: `layout: "stack" | "row"` (по умолчанию `stack`); у пункта `icon` (`IconName`) и `title`. `row` —
  подпись и значение в одной строке для «О задаче», строки 36px, длинное значение с многоточием, полный текст в `title`
  (у строки-значения — сам).

### Изменено
- `Button`: кольцо фокуса `accent` 2px с отступом 2px на всех вариантах.
- Правило ширины: экраны webapp — контейнер `page`, содержимое 1180px, паддинги снаружи (`docs/patterns/container.md`,
  foundations); `wide` 1200 — устарело.
- Словарь в примерах и превью: «Блокер» → «Ошибка», «Круг» → «Возвраты».

### Что обновить в платформе
- Тег `#v0.3.0`.
- Фаза в строке перехода журнала — `<Pill tone="ink">`.
- Блок «О задаче» — `<DescriptionList layout="row" items={[{ label, icon, value, mono?, title? }]} />`.
- Контейнер страницы — `max-width: 1180px` содержимого на всех экранах.
