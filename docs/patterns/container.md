# Container

Центрированная обёртка с максимальной шириной и горизонтальными паддингами для страниц с Topbar.

**Компонента нет.** Слои раскладки в систему не входят: экран задаёт ширину локально, отступы — шагами `space-*`.
Повторное использование — повод для заявки в дизайн-систему.

## Ширины (база 2026-05)

| Размер | Ширина | Где |
|---|---|---|
| `narrow` | 580px | заголовок и описание страницы настроек |
| `reading` | 920–940px | основная колонка настроек |
| `page` | 1180px | все экраны webapp, включая онбординг из двух колонок и страницы из трёх колонок |
| `wide` | 1200px | устарело: страницы из трёх колонок теперь в `page` |

Паддинг страницы в базе — 36px 32px 60px; на текущей шкале — `space-9`, `space-8` и `space-15`.

**Экраны webapp — `page` 1180px.** Одна ширина на всех экранах продукта (карточка задачи, страница решения,
«Мои решения», сессия агента, настройки, онбординг): 1180px — ширина **содержимого** (`box-sizing: content-box`,
`max-width: 1180px`), паддинги `space-9` `space-8` `space-15` — снаружи неё, контейнер по центру. Так в макете
«Карточка задачи» (HIR-49). `narrow` и `reading` — ширина колонки текста внутри `page`, а не отдельный контейнер.

## Когда применять

- Все экраны продукта с Topbar: карточка задачи, страница решения, «Мои решения», сессия агента, настройки, онбординг.
- Ширина одна — `page`; колонки и боковые панели раскладываются внутри неё.

## Когда не применять

- Auth-экраны со SplitLayout: колонки занимают всю ширину.
- Страница внутри оболочки приложения с сайдбаром: ширину задаёт колонка оболочки.
- Центрированная карточка (подтверждение почты, сброс пароля): ширину задаёт карточка.

## Антипаттерны

- Произвольная ширина (1037px) вместо значения из таблицы.
- Container внутри Container.
- Паддинги вне шкалы.
