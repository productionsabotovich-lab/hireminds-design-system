# SplitLayout

Двухколоночная раскладка auth-экрана: слева контекст (AsidePanel), справа форма (MainPanel).

**Компонента нет.** Слои раскладки в систему не входят: экран собирает сетку локально. Повторное использование —
повод для заявки в дизайн-систему.

## Раскладка (база 2026-05)

| `ratio` | Колонки | Где |
|---|---|---|
| `wide` (по умолчанию) | `1fr 480px` | вход, регистрация, восстановление пароля |
| `balanced` | `1fr 1fr` | сравнение вариантов в макетах |

Высота — не меньше высоты экрана; граница между колонками — `1px solid line` справа у левой колонки.

## Когда не применять

- Центрированная карточка (подтверждение почты, сброс пароля): одна карточка по центру.
- Онбординг: Topbar, основная колонка и боковая.
- Дашборд: оболочка приложения с сайдбаром.

## Антипаттерны

- SplitLayout на онбординге: пропадают путь и шаги в Topbar.
- Левая колонка только с логотипом: если показать нечего — центрированная карточка.
- Форма слева: форма всегда справа.
