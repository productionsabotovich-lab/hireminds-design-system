# Topbar

Верхняя панель страницы со слотами left, center и right в вариантах `app` и `auth`.

**Компонент:** [Topbar](../../components/Topbar/README.md) — пропсы и точные значения в README компонента. Статус
в правом слоте auth-панели — [TopbarStatus](../../components/TopbarStatus/README.md).

## Слоты вместо под-компонентов

Раскладка тривиальна (лево | центр | право), содержимое слотов — внешние компоненты; Topbar не отдаёт свои классы наружу.

## Варианты

| Вариант | Где |
|---|---|
| `app` (по умолчанию) | страницы внутри продукта |
| `app` и Crumb в центре | вложенные страницы: онбординг, настройки |
| `app` и вкладки в центре | раздел с подразделами |
| `app` и шаги справа | мастер: StepIndicator или TopbarSteps (компонента нет) |
| `auth` | публичные страницы: вход, регистрация, восстановление, подтверждение |

## Содержимое слотов

| Слот | Что |
|---|---|
| `left` | Brand — всегда; при необходимости переключатель workspace справа от него |
| `center` | Crumb, вкладки, поиск |
| `right` | действия, шаги, TopbarStatus; меню аккаунта — всегда последним |

## Когда не применять

- Модалки: у них своя шапка.
- Маркетинговый лендинг.

## Антипаттерны

- Высота `app` больше 50px.
- Размытие и «стекло».
- Тень при прокрутке: нижней границы достаточно.
- Тёмная панель `ink`.

## Устарело

- Меню аккаунта `AccountMenu` в правом слоте — компонента нет; аватар — UserAvatar.
