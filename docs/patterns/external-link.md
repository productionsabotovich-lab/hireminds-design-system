# ExternalLink

Текстовая ссылка в трёх стилях: ссылка футера, подчёркнутая ссылка в тексте и зелёная ссылка-действие со стрелкой.

**Компонент:** [ExternalLink](../../components/ExternalLink/README.md) — пропсы и точные значения в README компонента.

## Варианты

| Вариант | Где |
|---|---|
| `footer` | ссылки футера status, docs, security — обычно через LinkBar |
| `inline` | ссылки внутри текста: юридический текст, пояснения |
| `action` | переход на внешний сайт за действием («Получить на console.anthropic.com»), с `newTab` |

## Когда не применять

- Навигация внутри приложения — NavLink.
- Главное действие формы — Button.
- Возврат на предыдущий шаг — BackLink.

## Антипаттерны

- Вес 700.
- Подчёркнутые ссылки футера.
- Ссылка в тексте без подчёркивания.

## Устарело

- Кегль `action` 11.5–13px — в компоненте 12px.
