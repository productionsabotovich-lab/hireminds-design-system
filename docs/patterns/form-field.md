# Field

Поле формы: подпись, инпут и ошибка — базовая единица любой формы.

**Компонент:** [Field](../../components/Field/README.md) — обёртка над [Input](../../components/Input/README.md) с теми же
пропсами. Подсказка под полем — [Help](../../components/Help/README.md).

## Проп `font`

Шрифт значения — явное перечисление `font: "ui" | "mono"`, а не булев `mono`: новые варианты добавляются без поломки API.

| Значение | Когда |
|---|---|
| `ui` (по умолчанию) | email, пароль, имя, название |
| `mono` | API-ключи, токены, одноразовые коды, slug, хэши |

`mono` выбирается, когда значение не читается как естественный язык и опечатка ломает функцию.

## Композиция формы

- Поля столбцом через `space-4` (Stack `gap={4}`), перед главной кнопкой — ещё `space-2`.
- Ошибка поля — проп `error` под полем, а не Plate.
- Пароль: кнопка показа появляется сама при `type="password"`; PasswordEyeToggle наружу не экспортируется.
- Поле с префиксом и действиями (ключ API с копированием) — KeyInput, компонента нет.

## Когда не применять

- Многострочный ввод — компонента Textarea нет.
- Выбор из списка — Select; из двух-трёх вариантов — Switcher.
- Переключатель «вкл/выкл» и поиск с подсказками — компонентов Switch и Combobox нет.

## Антипаттерны

- Подпись справа от поля.
- Подпись в верхнем регистре: это kicker.
- Плейсхолдер вместо подписи.
- Ошибка поля в Plate.
- `mono` для email и имени.

## Устарело

- Зазор между полями `--space-7` (14px) — `space-4`.
- Рамка поля `line-2` — `line-3`.
