# Plate

Плашка-уведомление внутри потока страницы: иконка и текст в одном из четырёх тонов.

**Компонент:** [Plate](../../components/Plate/README.md) — пропсы и точные значения в README компонента.

## Варианты

| Вариант | Смысл |
|---|---|
| `success` | действие выполнено |
| `warning` | предупреждение: без условия продукт работает не полностью |
| `error` | ошибка: что случилось и что сделать |
| `info` | нейтральная справка |

## Когда применять

- Статус внутри формы или страницы, не перекрывающий содержимое.
- Текст в 1–3 строки; иконка подставляется по варианту автоматически.

## Когда не применять

- Всплывающее уведомление в углу экрана — не Plate.
- Диалог с действиями — ConfirmDialog.
- Подсказка по наведению — компонента Tooltip нет.
- Ошибка конкретного поля — проп `error` у Field.

## Антипаттерны

- Plate без иконки.
- Вариант не по смыслу: зелёный акцент у предупреждения.
- Plate вместо Card для большой секции.
- Несколько Plate подряд: вместо них список в Card.

## Устарело

- Текст `error` цветом `danger` (4.1:1) — в компоненте `danger-ink` (9.9:1).
