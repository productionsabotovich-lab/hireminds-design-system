# Pill

Бейдж состояния: одно слово или именная группа на мягкой заливке своей цветовой семьи; не кликабелен.

**Компонент:** [Pill](../../components/Pill/README.md) — пропсы и точные значения в README компонента.

## Тоны

| Тон | Состояние |
|---|---|
| `accent` | идёт сейчас; успех и «пройдено» |
| `warn` | ждёт решения, возврат, просрочка |
| `danger` | блокер, ошибка, лимит |
| `dim` | завершено, отменено, нейтральное |

Соответствие состояниям запуска и правила точки с пульсом — в README компонента; общее правило цвета —
[умеренный монохром](../foundations.md#умеренный-монохром).

## Когда применять

- Состояние записи в таблице и карточке.
- Статус рядом с заголовком страницы — `size="md"`.
- Статус подключения, метка модели.

## Когда не применять

- Действие — Button; выбор — Chip (компонента нет).
- Длинный текст — Plate.
- Номер шага — StepIndicator; счётчик — бейдж NavLink.
- Уведомление на всю ширину — Banner (компонента нет) или Plate.

## Антипаттерны

- Pill без тона на сером фоне.
- Длинный текст внутри: подробности пишутся рядом.
- Точка без ореола у `accent` и `warn`.
- Разные шрифты у соседних бейджей.
- Больше одного Pill в строке таблицы.

## Устарело

- Тоны `accent`, `warn`, `dim` — добавлен `danger`.
- Высота `sm` 17px и кегль 9.5px — в компоненте 20px и 11.5px: текст в таблицах должен читаться.
- Текст `warn` числом `oklch(0.42 0.12 65)` — в компоненте токен `warn-ink`.
