# Stack

Вертикальная раскладка: дети в колонку с отступом из шкалы `space-*`; самый частый примитив раскладки.

**Компонент:** [Stack](../../components/Stack/README.md) — пропсы и точные значения в README компонента.

## Когда применять

- Колонка полей формы — `gap={4}`.
- Список кнопок входа через SSO.
- Страница из секций — `gap={6}`; секция из заголовка и таблицы — `gap={3}`.
- Список однотипных строк — `as="ul"`.

## Когда не применять

- Элементы в строку — Cluster.
- Сетка колонок — локальный grid экрана.
- Сложная вложенная композиция — Card или составной компонент.

## Антипаттерны

- `<div style={{ display: "flex", flexDirection: "column", gap: 8 }}>` в экране вместо Stack.
- Stack без отступа: это обычный блок.
- Отступ вне шкалы.
- Внешние `margin` у детей Stack.

## Устарело

- Строковые шаги `"1"`…`"15"` по старой шкале — в компоненте числа `1`…`17` по шкале 4px.
- `as="form"` — в компоненте `div`, `section`, `main`, `ul`, `ol`; форма оборачивает Stack.
