# Switcher

Компактный переключатель из двух-трёх вкладок на сером треке.

**Компонент:** [Switcher](../../components/Switcher/README.md) — пропсы и точные значения в README компонента.

## Когда применять

- Два-три взаимоисключающих варианта в форме: вход и регистрация, тема, период оплаты.
- Содержимое перестраивается по выбранной вкладке.
- Подписи в одно-два слова.

## Когда не применять

- Четыре варианта и больше — Select.
- Несколько значений сразу — Chip (компонента нет).
- Переход между страницами — NavLink.
- Отправка формы — Button: Switcher только меняет состояние.

## Антипаттерны

- Активная вкладка цвета `accent`: переключатель нейтральный.
- Трек без фона `inset`.
- Вкладки высотой с кнопку.
- Трек на всю ширину.
