# Brand

Знак Hireminds — буква на графитном квадрате — и название рядом: опознание продукта с первого взгляда.

**Компонент:** [Brand](../../components/Brand/README.md) — пропсы и точные значения в README компонента. Правила
знака — в [брендбуке](../brand.md), раздел «Иконография».

## Варианты

| Вариант | Когда | Как |
|---|---|---|
| По умолчанию | Topbar `app` и `auth` | `<Brand />` |
| С переходом | возврат на главную | `href` (по умолчанию `/`) или `onClick` |
| Знак рабочего пространства | переключатель workspace | `mark` и `name` |
| Знак без названия | фавикон, мелкие размеры | пропа нет; в базе — открытая задача `markOnly` |

## Когда применять

- Левый слот каждого Topbar.
- Якорь над центрированной auth-карточкой.
- Шапка писем.

## Когда не применять

- Внутри содержимого страницы как декор.
- Знак роли агента — RoleCard (компонента нет); аватар человека — UserAvatar.

## Антипаттерны

- Замена буквы SVG-логотипом без решения владельца.
- Знак 32px и больше.
- Знак цвета `accent`: знак всегда `ink`.
- Знак без названия на страницах приложения.
