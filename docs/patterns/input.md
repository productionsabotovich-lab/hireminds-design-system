# Input

Однострочное текстовое поле: текст, email или пароль; шрифт `ui` или `mono`.

**Компонент:** [Input](../../components/Input/README.md) — пропсы и точные значения в README компонента. В формах
используется [Field](form-field.md).

## Когда Input напрямую

- Поле без подписи и ошибки: поиск в Topbar, фильтр над таблицей.
- В формах — Field: подпись, поле и ошибка вместе.

## Состояния

| Состояние | Вид |
|---|---|
| Покой | рамка `line-3`, фон `surface`, плейсхолдер `dim` |
| Фокус | рамка `accent`, кольцо `accent-soft` |
| Ошибка | рамка `danger`; на фокусе кольцо `danger-soft` |
| Disabled | фон `bg-2`, текст `mute` |

## Антипаттерны

- Голый `<input>` в экране.
- `font="mono"` для email и пароля.
- Инлайн-радиус или HEX-цвет рамки.
- Своя тень вне кольца фокуса и ошибки.

## Устарело

- Рамка `line-2` (1.4:1) — `line-3` (3:1).
