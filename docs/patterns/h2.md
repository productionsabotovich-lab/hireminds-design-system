# H2

Заголовок секции на display-шрифте: шапка секции 15px или крупный hero 38px.

**Компонент:** [H2](../../components/H2/README.md) — пропсы и точные значения в README компонента.

## Когда применять

- `section` — заголовок секции настроек и шагов онбординга.
- `hero` — крупный заголовок пустого дашборда, когда полная связка StageHeader не нужна.

## Когда не применять

- Заголовок страницы — H1.
- Подсекция внутри секции — H3.
- Шапка Card — строковый `header` у Card.
- Заголовок раздела со счётчиком над таблицей — SectionHeader.

## Антипаттерны

- Локальный класс с 15px вместо H2.
- H2 на `font-ui`.
- H2 как промежуточный размер между H1 и текстом: H2 — либо шапка секции, либо hero.

## Устарело

- Кегль `section` 15–15.5px и `hero` 38–46px — в компоненте 15 и 38px.
