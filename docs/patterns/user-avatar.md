# UserAvatar

Аватар человека или агента: фото или инициалы на градиенте `accent` или на сплошном цвете; круг или квадрат.

**Компонент:** [UserAvatar](../../components/UserAvatar/README.md) — пропсы и точные значения в README компонента.

## Форма и цвет

| Контекст | Форма | Цвет |
|---|---|---|
| Текущий пользователь: меню аккаунта, футер сайдбара | круг | градиент `accent` |
| Один из многих: таблица команды, список агентов, карточка утверждения | квадрат `r-sm` | сплошной `mute`, `ink-2` или `ink` |

Размеры: `xs` — список агентов в сайдбаре, `sm` — Topbar, `md` — футер сайдбара и таблица, `lg` — меню аккаунта.

## Когда не применять

- Логотип workspace и знак H — Brand.
- Иконка без инициала.

## Антипаттерны

- Радиус 8px у маленького аватара: выглядит иконкой.
- Вес инициалов 400: слишком тонко для белого на цветном.
- Градиент у всех аватаров: градиент — только текущий пользователь.
- HEX вместо токена для сплошного цвета.

## Расхождение с брендбуком

Градиент текущего пользователя идёт от `accent` к бирюзовому `oklch(0.55 0.16 200)`; в остальных элементах бирюза
брендбуком запрещена. Градиент применяется только в UserAvatar.

## Устарело

- Радиусы квадрата 4, 5 и 6px по размерам — в компоненте `r-sm` для всех размеров.
- Сплошные цвета числами `#707880`, `#2a2e35`, `#111418` — токены `mute`, `ink-2`, `ink`.
