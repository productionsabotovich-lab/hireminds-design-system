# PasswordStrengthMeter

Индикатор надёжности пароля: полоса из четырёх сегментов с оценкой и чеклист правил.

**Компонент:** [PasswordStrengthMeter](../../components/PasswordStrengthMeter/README.md) — пропсы и точные значения
в README компонента.

## Правила применения

- Поле нового пароля: регистрация и сброс пароля.
- Оценка 0–4 считается по характеристикам пароля; проверка утечек (`checkLeaked`) — HaveIBeenPwned в режиме
  k-anonymity: наружу уходит только начало SHA-1 хэша.
- Кнопка отправки неактивна, пока оценка ниже 3 или пароль найден в утечках: форма слушает `onScoreChange`
  и `onLeakedChange`.
- На форме входа индикатор не ставится: пароль уже существует.

## Когда не применять

- PIN и одноразовые коды.
- Колонки уже 240px.

## Антипаттерны

- HEX-оттенки красного, жёлтого и зелёного вместо семей OKLCH.
- Больше четырёх правил в чеклисте.
- Разные правила в разных формах.

## Устарело

- Отдельные атомы PasswordStrengthBar и PasswordChecklist для использования снаружи — в системе это внутренние части
  PasswordStrengthMeter, наружу они не экспортируются.
- Метки оценки WEAK, FAIR, GOOD, STRONG — в компоненте русские («слабый», «хороший · ~N лет»).
- Заливка сегментов светлыми оттенками `oklch(0.78 0.18 25)` и `oklch(0.78 0.18 65)` — в компоненте `danger`, `warn` и `accent`.
- Правила «длина, строчная, заглавная, цифра» — в компоненте «8+ символов», «хотя бы 1 цифра», «хотя бы 1 заглавная»,
  «не из leaked-списка».
