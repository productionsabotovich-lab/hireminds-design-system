# Caption

Мелкая техническая мета-подпись: mono в верхнем регистре или UI-текст 11.5px приглушённого цвета.

**Компонент:** [Caption](../../components/Caption/README.md) — пропсы и точные значения в README компонента.

## Два режима

- `font="mono"` — техническая метка: мета провайдера (`CLAUDE · 4.7`), ярлык группы сайдбара, ярлык метрики, версия.
- `font="ui"` — человеческая мета: «обновлено 21.05 · 09:23», «обязательные поля», счётчик символов «16 / 50».

## Когда не применять

- Подсказка под полем — Help.
- Надзаголовок над H1 — Kicker.
- Счётчик шага — StepIndicator.
- Цветной статус — Pill.
- Подпись бренда в футере — BrandSignature.

## Антипаттерны

- Mono без трекинга: читается как код.
- Кегль больше 13px: это Body.
- Цвет `ink`.
- Mono в верхнем регистре цвета `accent-ink` — это Kicker.

## Устарело

- Трекинг mono 0.04–0.14em и вес 500 — в компоненте 0.08em и вес 400 (`caption-mono`).
- Кегль UI 11–12px — в компоненте 11.5px (`caption-ui`).
