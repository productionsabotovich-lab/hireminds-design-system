# BackLink

Текстовая ссылка со стрелкой влево для возврата на предыдущий шаг флоу.

**Компонент:** [BackLink](../../components/BackLink/README.md) — пропсы и точные значения в README компонента.

## Когда применять

- Над формой: возврат к предыдущему экрану флоу («Вернуться ко входу»), в одной строке со StepIndicator.
- Под формой: исправить введённое («Не тот email? Изменить»).
- `variant="button"`: кнопка «Назад» в ряду действий многошагового флоу.

## Когда не применять

- Главное действие — Button.
- Ссылка внутри текста — ExternalLink `inline`.
- Пункт навигации — NavLink.

## Правила

- `subtle` — тихая ссылка цвета `mute`, на hover `ink`; `button` — цвет `ink-2`, фон появляется только на hover.
- Стрелка встроена и всегда смотрит влево.

## Антипаттерны

- Стрелка вправо: это ссылка вперёд — Button или ExternalLink `action`.
- Фон в покое у варианта `button`: такой BackLink становится Button.
- Жирный текст цвета `ink`: BackLink остаётся тихим.

## Устарело

- Проп `icon` (`arrow-left` или `chevron-left`) — в компоненте его нет, стрелка одна.
- Зазор стрелки и текста 6px — в компоненте `space-2`.
