# Crumb

Хлебные крошки в центральном слоте Topbar: путь от корня к текущей странице через шевроны.

**Компонент:** [Crumb](../../components/Crumb/README.md) — пропсы и точные значения в README компонента.

## Когда применять

- Страницы приложения с вложенностью: онбординг («Onboarding › Create workspace»), настройки
  («Settings › acme-engineering › General», slug — `mono`).
- `leadingChevron` — когда слева стоит Brand.

## Когда не применять

- Auth-экраны: в Topbar только Brand.
- Корень дашборда: вложенности нет.
- Узкий экран: вместо крошек — BackLink.

## Правила

- Разделитель — только SVG-шеврон, не «/» и не «→».
- Текущий сегмент не является ссылкой.
- Не больше четырёх сегментов.
- Крошки живут в центральном слоте Topbar.

## Устарело

- Кегль 12.5px и зазор 8px на страницах настроек — в компоненте 12px и 6px для всех случаев.
