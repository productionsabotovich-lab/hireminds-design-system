# H1

Главный заголовок страницы на display-шрифте; один на страницу.

**Компонент:** [H1](../../components/H1/README.md) — пропсы и точные значения в README компонента.

## Размеры

| Размер | Где |
|---|---|
| `display` (по умолчанию) | auth-формы, центрированные карточки, страницы ошибок |
| `hero` | заголовок с большим воздухом |
| `section` | шапка страниц дашборда и настроек |

Крупный заголовок левой колонки SplitLayout — StageHeader `aside`; заголовок формы — FormHeader.

## Когда не применять

- Заголовок внутри карточки — H2.
- Шаг онбординга — Kicker и заголовок в составе FormHeader.
- Название workspace в пути — Crumb.
- Заголовок модалки встроен в ConfirmDialog.

## Антипаттерны

- Размер через инлайн `font-size` или локальный класс: только проп `size`.
- `<h1>` для имени workspace в сайдбаре.
- Нулевой или положительный трекинг.

## Устарело

- Размеры 28/30/32, 38–46 и 22–26px — в компоненте 30, 42 и 24px; 46px — у StageHeader, 28px — у FormHeader.
