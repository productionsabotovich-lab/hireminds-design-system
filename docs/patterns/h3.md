# H3

Подзаголовок внутри блока на display-шрифте: карточка-шаг 15px или строка 13.5px.

**Компонент:** [H3](../../components/H3/README.md) — пропсы и точные значения в README компонента.

## Когда применять

- `card` — заголовок карточки-шага в сетке.
- `inline` — шаг таймлайна, заголовок блока доверия, строка опасной зоны.

## Когда не применять

- Шапка секции — H2.
- Имя в строке списка команды — текст строки, а не заголовок.
- Метка — Kicker или Caption.

## Антипаттерны

- H3 как заголовок страницы.
- Обычный текст, обёрнутый в H3.
- H2 и H3 подряд без воздуха: между ними не меньше `space-4`.

## Устарело

- Кегль `inline` 13–14px — в компоненте 13.5px.
