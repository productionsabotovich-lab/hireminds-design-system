# Chip

Выбираемый круглый тег: переключается кликом, выбранный подсвечен мягким зелёным с точкой.

**Компонента нет.** Заявка в дизайн-систему. README Select и Switcher уже направляют множественный выбор на чипы.

## Когда применять

- Множественный выбор тегов и категорий.
- Фильтры с несколькими значениями одновременно.
- Мелкие вторичные действия рядом с полем: загрузить логотип, сменить цвет.

## Когда не применять

- Статус только для чтения — Pill.
- Один вариант из двух-трёх — Switcher; из четырёх и больше — Select.
- Полноценное действие — Button `secondary`.
- Навигация — NavLink.

## Анатомия (база 2026-05)

- Высота 30px, паддинг 0 12px (`space-3`), радиус 999px, рамка `line`, фон `surface`.
- Текст `font-ui` 12px, вес 500, трекинг −0.005em, цвет `ink-2`; зазор точки и текста 5px (вне шкалы).
- Hover — фон `bg-2`.
- Выбранный — фон `accent-soft`, рамка прозрачная, текст `accent-ink`, точка 5px `accent`.
- Переход фона и рамки — 120ms.

## Правила

- Реакция на hover и выбранное состояние обязательны.
- Подпись до 40 символов.
- Рамка в покое обязательна: без неё тег сливается с фоном. При реализации рамка проверяется на 3:1 как граница
  контрола.
