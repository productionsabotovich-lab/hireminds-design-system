# Divider

Разделитель 1px: основной, усиленный, пунктирный, вертикальный или с подписью по центру.

**Компонент:** [Divider](../../components/Divider/README.md) — пропсы и точные значения в README компонента.

## Виды

| Вид | Как | Где |
|---|---|---|
| Основной | `weight="subtle"` (`line`) | границы секций, строки списка |
| Усиленный | `weight="strong"` (`line-2`) | над закреплённым рядом действий |
| Пунктир | `weight="dashed"` (`line-2`) | строки подсекции, примечание под карточкой |
| Вертикальный | `orientation="vertical"` | колонки разделённой карточки |
| С подписью | `label="или email"` | между входом через SSO и формой |
| Точка-разделитель | Dot `variant="separator"` | фрагменты меты, ссылки футера |

## Когда не применять

- Рамка элемента — `border: 1px solid line` на самом элементе.
- Декоративный штрих.
- Внутри Cluster, где элементы уже разведены отступом.

## Антипаттерны

- Толщина 2–3px, цвет вне `line` и `line-2`.
- Пунктир для главного разделителя: пунктир означает слабую связь.
- Двойной разделитель сверху и снизу одного элемента.

## Устарело

- Трекинг подписи 0.14em — в компоненте 0.1em (`divider-label`).
