# Button

Основной контрол действия: четыре варианта и три размера; главная кнопка графитная, а не зелёная.

**Компонент:** [Button](../../components/Button/README.md) — пропсы и точные значения в README компонента.

## Выбор варианта

| Ситуация | Вариант |
|---|---|
| Главное действие экрана, отправка формы | `primary` |
| Отмена, тихое действие | `ghost` |
| Альтернативное действие в той же форме | `secondary` |
| Разрушительное действие: удаление, отзыв | `danger` |
| Действие в футере карточки | `secondary` или `ghost` |

## Выбор размера

| Ситуация | Размер |
|---|---|
| Отправка auth-формы | `lg` |
| Футер карточки настроек | `md` |
| Действие в строке списка, тулбар | `sm` |
| Действие в Topbar | `sm` или `md` |

## Когда не применять

- Навигация — BackLink, ExternalLink, NavLink.
- Ссылка внутри абзаца — ExternalLink `inline`.
- Переключатель вариантов — Switcher; компонентов Checkbox и Switch нет.
- Огромная кнопка на полэкрана: в Frost Graphite нет hero-кнопок.

## Антипаттерны

- `primary` с заливкой `accent` — самая частая ошибка генерации интерфейсов.
- `secondary` для удаления: риск не виден.
- Несколько кнопок `danger` в одном флоу удаления: одна `danger`, остальные `ghost`.
- Радиус 999px.
- Своя тень на hover: hover меняет только цвет.

## Устарело

- Проп `label` — подпись передаётся через `children`.
- Пропы `iconLeft` и `iconRight` — один проп `icon`, иконка перед подписью.
- Подпись, заменяемая спиннером, — при `loading` спиннер встаёт на место иконки, подпись остаётся.
