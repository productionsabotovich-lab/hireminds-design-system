# BrandSignature

Микро-подпись бренда в футере: `HM · S2 · 2026` — mono, верхний регистр, цвет `dim`, без знака.

**Компонент:** [BrandSignature](../../components/BrandSignature/README.md) — пропсы и точные значения в README компонента.

## Сегменты

- `HM` — инициалы Hireminds.
- `S2` — номер сезона (релиза); вместо него допустима версия области: `auth.v2`.
- Год — последний сегмент.
- Разделитель « · » — символ в тексте, а не Dot.

## Когда применять

- Левая часть PageFooter `between` и начало строки PageFooter `inline`.

## Когда не применять

- Topbar — там Brand.
- Мета с данными (число агентов, решений) — MetaLine (компонента нет) или Caption.

## Антипаттерны

- Кегль больше 11px.
- Текст без верхнего регистра.
- Цвет `ink`: подпись остаётся фоновой.

## Устарело

- Трекинг 0.04–0.08em — в компоненте 0.06em (`signature`).
