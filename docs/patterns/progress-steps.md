# ProgressSteps

Индикатор шагов флоу сброса пароля; в библиотеку не входит.

**Компонента нет, и он не создаётся.** Решение владельца от 2026-05-25: индикатор специфичен для одного экрана
восстановления пароля. Если похожий индикатор понадобится в другом флоу, он проектируется заново под новый контекст,
а не переносится отсюда.

## Как показывается шаг

- Текстовым суффиксом в kicker: `RESET PASSWORD · STEP 3 / 3` — Kicker или FormHeader.
- Отдельной mono-строкой — StepIndicator.
