# PageFooter

Нижняя строка страницы: подпись бренда и футерные ссылки — по краям, по центру или в одну строку.

**Компонент:** [PageFooter](../../components/PageFooter/README.md) — пропсы и точные значения в README компонента.

## Данные вместо частей

Внутри две фиксированные части — BrandSignature и LinkBar; потребитель передаёт данные (`brand`, `links`), а не
собирает части руками.

## Раскладки

| `layout` | Где |
|---|---|
| `between` (по умолчанию) | колонка формы на входе и восстановлении пароля |
| `center` | центрированные карточки подтверждения почты |
| `inline` | левая колонка auth-экрана, auth-лейаут с карточкой по центру: всё в одну строку через точки |

## Когда не применять

- Дашборд и настройки: навигация в сайдбаре.
- Модалка: внизу кнопки.
- Онбординг: внизу закреплённый ряд действий.

## Антипаттерны

- Разные шрифты у подписи и ссылок.
- Цвета `accent` и `danger`: футер остаётся тихим.

## Устарело

- Отступ сверху 28–36px — в компоненте `space-7` (28px).
