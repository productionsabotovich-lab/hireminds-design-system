# Card

Белая карточка с тонкой рамкой и слотами header, body и footer — основная единица композиции страницы.

**Компонент:** [Card](../../components/Card/README.md) — пропсы и точные значения в README компонента.

## Слоты вместо под-компонентов

Порядок частей фиксирован (header → body → footer), у частей нет своей логики, строковый `header` сам становится
заголовком. Поэтому Card описывается пропсами и JSON-ом; под-компоненты `Card.Header` и `Card.Body` не нужны.

## Варианты

| Вариант | Как |
|---|---|
| Стандартный | `header`, `children`, `footer` |
| Без шапки | без `header` |
| Без футера | без `footer` |
| Шапка с иконкой или бейджем | `header` как ReactNode |
| Карточка провайдера (логотип, имя, бейдж) | компонента нет; в базе — открытая задача `ProviderCard` |

## Когда применять

- Логическая группа на странице: форма, секция настроек, информационный блок.
- Нужен явный заголовок секции — `header`; действия внизу — `footer`.

## Когда не применять

- Короткое сообщение с иконкой — Plate.
- Окно поверх страницы — ConfirmDialog.
- Маленький тег — Pill.
- Пустой список — EmptyState.

## Антипаттерны

- Card без фона `surface`: тогда нужен обычный `<section>`.
- Card внутри Card: две секции вместо вложенности.
- Радиус от 12px, своя тень вместо `sh-1`.

## Устарело

- Обращения `<Card.Header>` и `<Card.Body>` из таблицы замен базы — в компоненте только пропы.
