# Help

Подпись под полем формы: что вводить или результат проверки.

**Компонент:** [Help](../../components/Help/README.md) — пропсы и точные значения в README компонента.

## Тоны

| Тон | Когда |
|---|---|
| `default` | что ввести, ограничения: «3–50 символов» |
| `error` | ошибка проверки |
| `success` | подтверждение: «slug свободен» |

## Когда применять

- Подсказка под полем, живая проверка ввода, пояснение под значением.

## Когда не применять

- Над полем — подпись поля (`label`).
- Между секциями формы — H3 или Caption `ui`.
- Под крупным заголовком — Lead.
- Ошибка, которую Field выводит сам через `error`, не дублируется.

## Антипаттерны

- Кегль 13px: это Body.
- Mono: путается с Caption и Kicker.
- Зазор от поля меньше 6px.

## Устарело

- Кегль 11.5–12px — в компоненте 11.5px (`help-text`).
