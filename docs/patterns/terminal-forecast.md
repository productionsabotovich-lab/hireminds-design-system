# TerminalForecast

Светлый моноширинный блок «что произойдёт после»: последствия действия до его выполнения.

**Компонент:** [TerminalForecast](../../components/TerminalForecast/README.md) — пропсы и точные значения в README компонента.

## Когда применять

- После ввода ключа: что запустится.
- Перед созданием рабочего пространства, наймом агента, утверждением: что изменится.

## Когда не применять

- Случившиеся события — TerminalBox `log`.

## Антипаттерны

- Блок для реальных событий вместо прогноза.
- Вложение в TerminalBox.
- Тёмная палитра терминала внутри блока.

## Связано

[TerminalBox](terminal.md).
