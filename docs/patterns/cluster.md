# Cluster

Горизонтальная раскладка: дети в строку с отступом из шкалы и переносом.

**Компонент:** [Cluster](../../components/Cluster/README.md) — пропсы и точные значения в README компонента.

## Когда применять

- Ряд кнопок (отмена и подтверждение), тулбар над таблицей.
- Знак и название, точка и подпись, группа бейджей.
- Ссылки футера, сегменты пути.
- Шапка «заголовок слева — действия справа» — `justify="between"`.

## Когда не применять

- Вертикальный список — Stack.
- Сетка с выравниванием по ячейкам — локальный grid экрана.
- Абсолютное позиционирование.

## Правила

- Отступ — шаг шкалы: кнопки рядом `gap={2}`, группы тулбара `gap={3}`, заголовок и тулбар `gap={4}`.
- Перенос включён по умолчанию: на узком экране тулбар уходит на вторую строку.

## Антипаттерны

- `<div style={{ display: "flex", gap: 14 }}>` в экране вместо Cluster.
- `justify="between"` при одном ребёнке.
- Отступ вне шкалы.

## Устарело

- Строковые шаги `"1"`…`"11"` по старой шкале — в компоненте числа `1`…`17` по шкале 4px: `gap={2}` = 8px.
- `justify="center"` — в компоненте только `start`, `end` и `between`.
