# KeyInput

Поле для API-ключей и секретов: mono, иконка-префикс, кнопки показа и копирования, значение скрыто по умолчанию.

**Компонента нет.** Заявка в дизайн-систему; до её реализации ключ вводится через Field с `font="mono"`.

## Когда применять

- Ввод ключа API и токена интеграции.
- Просмотр сохранённого ключа в маске с возможностью показать.

## Когда не применять

- Email и имя — Field.
- Пароль входа — Field `type="password"`.
- Поиск и многострочный текст.

## Анатомия (база 2026-05)

- Контейнер: высота 42px, рамка `line`, радиус `r-md`, фон `surface`; фокус внутри — рамка `accent` и кольцо 3px `accent-soft`.
- Префикс: иконка (ключ, замок) цвета `dim`, паддинг 0 10px.
- Значение: `font-mono` 12.5px, трекинг 0.02em, `ink`, без своей рамки.
- Действия: кнопки 28px с радиусом `r-sm`, иконки `dim`, на hover фон `inset` и иконка `ink`; зазор 4px.
- Варианты: полный (префикс, показ, копирование) для первого ввода; маска с показом для сохранённого ключа;
  компактный без префикса внутри карточки.

## Правила

- Значение скрыто по умолчанию, показ — по кнопке.
- Кнопка показа обязательна: пользователь проверяет вставленное.
- При реализации рамка и фокус приводятся к правилам Input: рамка контрола `line-3`, кольцо 2.5px.
