# SaveBar

Закреплённая внизу тёмная панель несохранённых изменений: точка, список изменённых полей, «Отменить» и «Сохранить».

**Компонента нет.** Заявка в дизайн-систему. Описание базы расходится с двумя действующими правилами; реализация
начинается с решения владельца по этим пунктам.

## Расхождения с действующими правилами

- Тёмная поверхность `ink`: в системе единственная тёмная поверхность — TerminalBox.
- Кнопка «Сохранить» залита `accent`: главная кнопка — `ink`, `accent` кнопки не заливает.
- Цвета текста и рамки (`#cbcfd3`, `#3a3f47`) и тень `0 12px 32px -8px rgba(17,20,24,.4)` заданы вне токенов.

## Анатомия (база 2026-05)

- `position: sticky`, отступ снизу 18px, паддинг 12px 18px, радиус `r-xl`, зазор 14px.
- Слева — точка `warn` 6px с ореолом и текст 12.5px: «2 несохранённых изменения · Название, Описание».
- Справа — «Отменить» (прозрачная, с рамкой) и «Сохранить» (с галочкой): высота 32px, радиус `r-sm`, 12.5px, вес 500.

## Когда применять

- Страница настроек с несколькими полями и несохранёнными изменениями.

## Когда не применять

- Модалка: у неё свой футер.
- Форма из одного поля (вход, восстановление пароля): кнопка в форме.
- Шаг мастера: навигация «Назад» и «Далее».
- Подтверждение опасного действия — ConfirmDialog.

## Антипаттерны

- Панель без `sticky`: пропадает при прокрутке.
- Панель без списка изменений: непонятно, что сохраняется.
