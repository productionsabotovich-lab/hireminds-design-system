# NavLink

Пункт боковой навигации: иконка, подпись и счётчик или метка «soon»; активный пункт подсвечен мягким зелёным.

**Компонент:** [NavLink](../../components/NavLink/README.md) — пропсы и точные значения в README компонента.

## Состояния

| Состояние | Вид |
|---|---|
| Покой | прозрачный фон, текст `ink-2`, приглушённая иконка |
| Hover | лёгкая графитная подложка |
| Активный | `accent-soft` с прозрачностью, текст `ink`, вес 500, иконка `accent-ink` |
| Опасный | `tone="danger"`: текст `danger-ink`, иконка `danger` |

Бейдж: `count` — число моноширинным шрифтом; `soon` — раздел ещё не готов.

## Когда применять

- Сайдбар приложения: разделы продукта, счётчик непрочитанного.
- Сайдбар настроек: подразделы и пункт «Danger zone».

## Когда не применять

- Вкладки внутри формы — Switcher.
- Путь — Crumb.
- Ссылки футера — ExternalLink.
- Главное действие — Button.

## Сайдбар

Компонента сайдбара нет. При сборке действуют решения первой версии (журнал решений, 2026-05-27):

- шапка и футер сайдбара закреплены, прокручивается только середина;
- внутри рабочего пространства вместо логотипа сверху стоит переключатель workspace;
- элемент пользователя на страницах настроек — в футере сайдбара, а не в шапке страницы.

Ярлыки групп пунктов — Caption `mono`.

## Антипаттерны

- Активный пункт с весом 700 или сплошной заливкой `accent`.
- Инлайн-фон пункта вместо состояния `active`.
- Бейдж с цветной заливкой вне системы.

## Устарело

- Бейдж как произвольный ReactNode и под-компонент `NavLink.Badge` — в компоненте только объект `{ kind, value }`.
