# FormHeader

Шапка формы: kicker, заголовок 26–32px и вводный абзац; всегда выровнена влево.

**Компонент:** [FormHeader](../../components/FormHeader/README.md) — пропсы и точные значения в README компонента.

## Варианты

| Kicker | Абзац | Когда |
|---|---|---|
| есть | есть | онбординг, сброс пароля, страницы настроек |
| нет | есть | вход («С возвращением.») |
| есть | нет | минимальная шапка блока |

Kicker по умолчанию — `accent-ink` с точкой; тихий вариант — `kickerTone="mute"` и `withDot={false}`.

## Когда применять

- Над формой в колонке MainPanel.
- В шапке страниц онбординга и настроек.
- Вводная часть внутри Card.

## Когда не применять

- Левая колонка SplitLayout и hero — StageHeader.
- Центрированные карточки — Kicker, H1 `align="center"` и Lead.
- Модалка — шапка ConfirmDialog.

## Антипаттерны

- Заголовок 38–46px: это StageHeader.
- Свои отступы между частями: они встроены.

## Устарело

- Правило «kicker FormHeader всегда `mute` и без точки, `accent-ink` — признак StageHeader» — в компоненте по умолчанию
  `accent-ink` с точкой, тихий вариант задаётся пропсами.
- Отступы kicker → заголовок 6–14px и абзац → форма 26–32px — в компоненте 10px и 32px.
