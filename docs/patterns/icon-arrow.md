# IconArrow

Стрелка в едином стиле: arrow, chevron и send на сетке 24×24, цвет наследуется от текста.

**Компонент:** [IconArrow](../../components/IconArrow/README.md) — пропсы и точные значения в README компонента.
Общие правила иконок — [брендбук](../brand.md), раздел «Иконография».

## Формы

| Форма | Смысл | Где |
|---|---|---|
| `arrow` | действие, движение | кнопка «дальше», hero-CTA |
| `chevron` | навигация, раскрытие | разделитель пути, раскрывающийся список |
| `send` | отправка | кнопка «Отправить ссылку» |

## Правила

- SVG — для кнопок и CTA, где важна точная сетка; символ «→» — для ссылок внутри строки текста.
- Цвет — `currentColor`, задаётся родителем.
- Толщина штриха 1.6–2; размеры 11–18px по месту.
- BackLink, Crumb и ExternalLink `action` содержат свою стрелку; вторая не добавляется.

## Когда не применять

- Крупная декоративная графика.
- Самостоятельные иконки (глаз, копирование) — не IconArrow.
- Маркер списка — Dot или `::marker`.

## Антипаттерны

- Жёсткий цвет штриха (`stroke="#000"`): иконка не наследует цвет.
- Произвольная толщина штриха.
- Стрелка вместо шеврона в пути и списках: у форм разный смысл.
