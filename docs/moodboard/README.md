# Мудборд «B2 · Frost Graphite»

Мудборд — эталон настроения визуального языка Hireminds: дизайн-система построена на направлении
«B2 · Frost Graphite». Значения в мудборде — ориентир, а не источник: при расхождении действует
`tokens/tokens.json`, правила применения — [брендбук](../brand.md) и [основы](../foundations.md).

## Файл

[`Hireminds Moodboards.html`](Hireminds%20Moodboards.html) — самостоятельная HTML-страница: из внешних
ресурсов подключает только Google Fonts. Для просмотра файл открывается в браузере локально; GitHub
показывает его исходный код:
https://github.com/productionsabotovich-lab/hireminds-design-system/blob/main/docs/moodboard/Hireminds%20Moodboards.html

## Что на странице

- Пять направлений с одинаковой структурой: A · Linear-cool, B · Linear + green, C · Mono-lab, D · Editorial cool,
  E · Sharp green. В каждом — палитра, типографика, карточки ролей и мини-интерфейс со строками на утверждение.
- Две холодные вариации направления B: B1 · slate cool и B2 · frost graphite.
- Полноценный экран центра утверждений в направлениях B и B2.

Действующее направление — B2: блок «B2 · frost graphite» в разделе «+ Холоднее: B1 и B2» и раздел
«B2 · Frost + green · полноценный экран». Остальные направления — отклонённые варианты, решения из них не берутся.

## Что задаёт B2

- **Нейтрали.** Графитно-морозная шкала без синевы и без зелени: от почти белого фона до графитного текста.
- **Акцент.** Один зелёный, только точечно: активный пункт навигации, точка статуса, метка «CI ✓».
- **Плотность.** Как в Linear: строки списка 12.5px, тонкие разделители, моноширинные метки, счётчики и сроки.
- **Шрифты.** Inter Tight для заголовков, Inter для текста, Geist Mono для меток и цифр.
- **Кнопки.** Главное действие экрана — графитная кнопка, вторичное — белая с рамкой.
- **Навигация.** Боковая панель на утопленном фоне, ярлыки групп моноширинным шрифтом капителью, счётчики справа.

## Расхождения с действующей системой

| Элемент | В мудборде | Действует |
|---|---|---|
| Приглушённый текст | `#707880`, 4.0–4.5:1 на светлых фонах | `mute` затемнён: от 5.4:1 на любом фоне |
| Светлые метки и счётчики | `#9ba1a8`, около 2.6:1 | `dim` (4.65:1 на `bg`); на `bg-2` и `inset` — `mute` |
| Радиус карточки | 6px | `r-lg` |
| Радиус кнопки | 5px | `r-md` |
| Радиус квадратного аватара | 3–4px | `r-sm` |
| Радиус бейджа срока | 4px | Pill — круглый, 999px |
| Акцентное слово в заголовке | цвет `accent` | `<em>` цвета `accent-ink` |
| Кнопка действия в мини-интерфейсе | залита `accent` | главная кнопка — `ink`; зелёный только для состояний |
| Срочный срок «⚡ 3h 24m» | зелёный на `accent-soft` | срок и просрочка — `warn` (правило умеренного монохрома) |
| Высота верхней панели | 40px | Topbar `app` — 50px |
| Заголовок страницы | 20px | H1 `section` — 24px |
| Моноширинный шрифт | Geist Mono и JetBrains Mono | только Geist Mono (`font-mono`) |
| Карточка роли на тёмном фоне («ключевая») | показана | не утверждена, в системе нет — см. [RoleCard](../patterns/role-card.md) |
| Тексты интерфейса | частично на английском (Approvals, Pending, Filter) | интерфейс на русском — см. [брендбук](../brand.md) |

Имена, роли и задачи на мудборде — иллюстрация, а не тексты продукта.
