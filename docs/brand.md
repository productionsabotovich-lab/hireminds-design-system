**B2 · Frost Graphite.** Графитно-морозная палитра без синевы и без зелени в нейтралях, плотность в духе Linear, моноширинные подписи-метки и зелёный акцент строго точечно. Интерфейс собирается из атомов `Hireminds.*` — заголовки, текст, кнопки, поля, карточки; ни один блок страницы не верстается заново.

Настроение — [мудборд «B2 · Frost Graphite»](moodboard/README.md). Подробные правила — [основы](foundations.md) и [паттерны](patterns/README.md), значения — `tokens/tokens.json`; при расхождении действуют токены.

## Голос и текст

- Пиши интерфейс по-русски, на «вы» со строчной: «Отправим ссылку для сброса на вашу почту». Технические сущности оставляй как в продукте — workspace, BYOK, Dashboard, API key.
- Заголовки — sentence case, коротко и по делу: «Новый пароль», «Ключ API», «Настройки». Не ставь точку в заголовке.
- Kicker и технические метки — mono UPPERCASE с разделителем ` · `: `RESET PASSWORD · STEP 3 / 3`, `BYOK · Шаг 2 / 3`, `EMAIL CONFIRMED`. Регистр задаёт CSS, в коде пиши как удобно.
- Лента терминала — английский lowercase в стиле логов: `key stored`, `org resolved → acme-corp`, `ready`.
- Ошибки говорят, что случилось и что делать: «Ссылка устарела. Запросите новую.» Успех — одной фразой: «Email подтверждён. Теперь можно войти.»
- Кавычки — «ёлочки», тире — длинное с пробелами. Эмодзи не используем нигде.
- Акцентное слово в крупном заголовке оборачивай в `<em>` — H1, H2 и StageHeader красят его в `accent-ink`: «Ваша <em>AI-команда</em>».
- Пользователь в текстах — «вы» или «владелец», не «юзер».

## Цвет

- Фон страницы — `bg`; карточки, формы и поля — `surface`; вторичные плашки и hover — `bg-2`; утопленные элементы (трек Switcher, код-чип) — `inset`. Правило слоёв: глубже — темнее. Не клади `surface` поверх `bg-2`.
- Текст — шесть ступеней: `ink` для заголовков и основного текста, `ink-2` для подписей полей и текста кнопок, `ink-3` для вторичного, `mute` для lead и подписей, `dim` только для плейсхолдеров и mono-меток, `faint` для disabled и декора. Никаких произвольных серых HEX.
- Главная кнопка — `ink` с белым текстом, а не зелёная. Зелёный (`accent`) — только точки статуса, галочки, рамка фокуса и kicker (`accent-ink`).
- Умеренный монохром: интерфейс графитный, цвет — только для состояний. `accent` — успех и «пройдено», `warn` — возврат и просрочка, `danger` — ошибка и лимит. Метки, типы и категории нейтральные, ярлыки не раскрашиваются; красный и янтарь появляются только при реальной тревоге.
- Семантика ходит четвёрками: основа (`accent` / `warn` / `danger`), hover (`-2`), заливка (`-soft`), текст на заливке (`-ink`). Текст на `danger-soft` — `danger-ink`, а не `danger`.
- Нейтрали — HEX, цветные — OKLCH с одинаковой воспринимаемой светлотой. Не подменяй OKLCH на HEX-приближения.
- Запрещено: бирюза, фиолетовые градиенты, любые оттенки зелёного вне семьи `accent`, `color: black`. Белый `#fff` — только текст на `ink`, `danger` и `accent`.
- Контраст — не ниже WCAG AA. Текст: `mute` читается на любом фоне (от 5.4:1), `dim` — только на `bg` и `surface` (4.65:1), на `bg-2` и `inset` бери `mute`. `faint` — только disabled и декор. Текст на цветной заливке — всегда `-ink` своей семьи. Рамка поля ввода — `line-3` (3:1); `line` и `line-2` — только разделители.

## Типографика

- Три семейства, три роли. `display` (Inter Tight) — заголовки, имя бренда, KPI-цифры. `ui` (Inter) — всё остальное: текст, кнопки, поля, подписи. `mono` (Geist Mono) — kicker, шаги, API-ключи, код, лента терминала; никогда не для абзацев.
- Базовый текст — 13.5px / 1.45 (`body-base`). Шкала исторически дробная — 10.5, 11.5, 12.5, 13.5 — это осознанный ритм, не округляй.
- Заголовки: `h1-display` 30px для auth-форм, `form-heading` 28px в FormHeader, `h1-section` 24px для страниц дашборда, `h2-section` 15px для секций в карточках, hero — `h1-hero` 42px, `h2-hero` 38px, `stage-aside` 46px. Все — вес 600 и отрицательный трекинг от −0.01em до −0.038em.
- Mono всегда в паре с uppercase и разрядкой: `kicker-mono` 0.18em, `caption-mono` 0.08em, `signature` 0.06em, `divider-label` 0.1em. Mono без разрядки читается как код и путает контекст.
- Веса: 400 текст, 500 кнопки, подписи, kicker, 600 заголовки, 700 только буква-марка в Brand. Положительный трекинг на тексте `ui` не ставь.
- Используй атомы: H1, H2, H3, Lead, Body, Caption, Help, Kicker. Не задавай `font-size` руками в странице.

## Отступы, радиусы, тени

- Отступы — шкала `space-1`…`space-17` с шагом 4px (4 → 68). Типовые: `space-2` gap между кнопками, `space-4` паддинг Topbar и зазор полей формы, `space-6` между секциями страницы, `space-8` паддинг страницы. Внутри атомов встречаются точные значения из макетов (9px в Brand, 18px в Card) — их не подгоняй.
- Радиус растёт с уровнем элемента: `r-xs` 3px бейдж и код-чип, `r-sm` 5px вложенный таб, `r-md` 6px кнопка и поле, `r-lg` 8px карточка и плашка, `r-xl` 10px модалка. Круг — `999px` (точки, аватары-круги). Никаких 12–16px и никаких острых углов.
- Сначала граница, потом тень: Frost Graphite — «наклеенный», а не парящий. Card — `line` + `sh-1`; выпадающее меню — `sh-2`; `sh-3` только модалкам. Все тени построены на `rgba(17,20,24,…)` — RGB от `ink`, не на чёрном; цветных теней нет.
- Разделитель по умолчанию — `1px solid line`; усиленный — `line-2`; пунктир — `line-2` dashed. Граница контрола (поле ввода) — `line-3`.
- Форма — поля столбцом через `space-4` (16px), перед главной кнопкой ещё `space-2`. Значения из макетов, которых нет в шкале (14, 18px), округляй до ближайшего шага 4px вверх.

## Состояния и движение

- Фокус поля: рамка `accent` + кольцо `0 0 0 2.5px accent-soft`; у поля с ошибкой рамка `danger` и кольцо `danger-soft`. Кольцо само по себе почти невидимо (1.2:1) — фокус держит рамка.
- Hover: secondary и ghost кнопки уходят в `bg-2`, primary — в `ink-2`, danger — opacity 0.88. Disabled — opacity 0.45 и `not-allowed`.
- Переходы — 120ms по `background`, `color`, `border-color`. В приложении есть `rise` (появление снизу на 6px), `pop` (масштаб от 0.4), `blink` (курсор терминала), `scan`; держи их короткими (≈0.5s) и только на входе экрана.
- Загрузка в кнопке — проп `loading`, не отдельный Spinner рядом.
- Живое состояние — точка с пульсом рядом с текстом состояния («Выполняется»). Одинокая мигающая точка без текста («агент думает») не используется: работа описывается словами — «думает… читает спеку».

## Иконография

- Иконки — inline SVG в сетке 24×24, `stroke="currentColor"`, без заливки, `stroke-linecap/linejoin="round"`, толщина 1.6–2, размер 14–16px. Цвет наследуется от текста.
- Стрелки и шевроны — только через IconArrow (`arrow`, `chevron`, `send`). Иконки Plate зашиты в компонент.
- Новые иконки берутся из набора Lucide и приводятся к стилю штриха системы; иконки Lucide «как есть», без приведения, не используются. Пакет `lucide-react` зависимостью не подключён: иконка встраивается inline SVG.
- Логотипа-файла нет: знак — буква «H» на квадрате `ink` 26×26 с радиусом `r-md`, рядом имя в `display` 15px. Используй компонент Brand, не рисуй знак заново.
- Brand стоит в левом слоте каждого Topbar. Знак не заливается `accent`, не увеличивается до 32px и больше и не заменяется SVG-логотипом без решения владельца; на страницах приложения знак без имени не ставится.

## Терминал

TerminalBox — единственная тёмная поверхность. Его палитра зашита в CSS компонента и в токены не вынесена: фон `#0e1116`, граница `#1d2228`, текст `#e6e8eb`, приглушённое `#707880` и `#9ba1a8`, зелёный `oklch(0.78 0.16 150)`. Собирай ленту только из под-компонентов (TerminalLineOK, TerminalKV…), не стилизуй строки вручную. TerminalForecast — светлый моноширинный блок на токенах (`surface`, `inset`): тёмная палитра в него не переносится.

## Признаки шаблонного интерфейса

Эти приёмы делают экран похожим на типовой AI-продукт; в Hireminds их нет.

- Бирюзовый акцент и фиолетовые градиенты.
- Главная кнопка, залитая зелёным.
- Иконки из набора без приведения к стилю системы.
- Мигающая точка вместо слов о том, что происходит.
- Контейнеры, вложенные без причины: карточка в карточке, рамка вокруг ряда кнопок.

## Компоненты

- API props-driven: компонент описывается JSON-ом и рендерится агентом как Generative UI — `{ component: "Plate", variant: "success", children: "Email подтверждён" }`.
- Исходники компонентов живут в репозитории `hireminds-design-system` (`components/`). Приложение импортирует их оттуда, а превью этой страницы — собранный из них бандл `window.Hireminds` (стили в `components/bundle.css`, классы `<Компонент>_<класс>`).
- Порядок подключения в приложении: `tokens/tokens.css`, затем `styles/base.css`, шрифты Inter и Inter Tight (Google Fonts), Geist Mono — из `fonts/`.
- Снаружи не импортируй `.module.css` компонента и не переопределяй токены локально — только пропсы и экспортированные под-компоненты.

## Что ещё не сделано

- Слои раскладки Container, SplitLayout, AsidePanel, MainPanel и доменные блоки (auth, onboarding, settings) в систему не входят — их собирают экраны из атомов; Stack и Cluster в системе есть.
- Паттерны, которых пока нет в коде: Chip, TopbarSteps, KeyInput, SaveBar, BudgetCell, MetaLine, Banner, RoleCard — см. [каталог паттернов](patterns/README.md).
- Цвета вне токенов: рамки Plate, палитра терминала, фон активного NavLink — пока числами в CSS компонентов.
- Тёмной темы нет: система однотемная.
- Превью собираются на React 18, компоненты написаны под React 19 и работают в обоих. `checkLeaked` у PasswordStrengthMeter ходит в api.pwnedpasswords.com — в превью выключен.
