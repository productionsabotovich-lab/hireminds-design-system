# Plate

Плашка-уведомление внутри потока страницы с иконкой в четырёх тонах: успех, предупреждение, ошибка и информация.

## Когда использовать
- error: ошибка формы входа и регистрации, «Ссылка устарела или уже использована» на reset-password, ошибка создания workspace.
- success: «Пароль успешно изменён. Входим в аккаунт…» на reset-password.
- warning: «Ключ нужен, чтобы AI работал» на BYOK; info: «Не вижу письма? Проверь папку Спам» на email-sent.
- Ошибку конкретного поля показывай через `error` у Field или Input, длинный блок оформляй Card, всплывающее уведомление — не Plate.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| variant | `"success" \| "warning" \| "error" \| "info"` | `"info"` | Тон и иконка. |
| children | `ReactNode` | обязательный | Текст сообщения. |
| className | `string` | — | Дополнительный класс (отступы). |
| style | `CSSProperties` | — | Инлайн-стили, только для динамических значений. |

## Правила
- success: фон `accent-soft`, текст `accent-ink`. warning: `warn-soft` и `warn-ink`. error: `danger-soft` и текст `danger-ink` (9.9:1). info: фон `bg-2`, рамка `line`, текст `ink-3`. Рамка цветных вариантов — более тёмный oklch-оттенок той же семьи.
- Паддинг 12px 14px, gap 9px, радиус 8px (`r-lg`), шрифт 12px с line-height 1.45, без тени.
- Иконка 14px подставляется по варианту автоматически: не убирай её и не перекрашивай вариант.
- Текст в 1–3 строки; несколько Plate подряд замени списком в Card.

## Пример
```tsx
import { Plate } from "../index";

<Plate variant="error">Ссылка устарела или уже использована. Запроси новую — займёт несколько секунд.</Plate>
<Plate variant="success">Пароль успешно изменён. Входим в аккаунт…</Plate>
```
