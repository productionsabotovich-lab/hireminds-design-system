# PlanProgress

Прогресс плана сессии: «План 3 из 6» и одна тонкая сплошная полоса при любом числе пунктов; без плана — «План ещё не получен».

## Когда использовать
- Виджет сессии `SessionLive` `widget`, заголовок плана `SessionPlan` (с `label=""`: число уже в заголовке).
- Прогресс загрузки или шагов мастера — не здесь.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| done | `number \| null` | — | Выполнено пунктов; `null` — план от раннера ещё не получен. |
| total | `number` | `0` | Всего пунктов. |
| label | `string` | «План» | Подпись перед числом; `""` — без подписи. |

## Правила
- Полоса 4px без сегментов: при 26 пунктах сегменты не различить. Дорожка `line-2`, заполнение `accent`, радиус `r-xs`.
- Подпись — `Caption` mono `dim`: «План 3 из 6»; для читалки — «План: выполнено 3 из 6» (`role="img"`).

## Пример
```tsx
<PlanProgress done={3} total={6} />
```
