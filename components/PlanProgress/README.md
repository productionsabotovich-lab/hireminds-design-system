# PlanProgress

Индикатор плана сессии сегментами: подпись «План 3 из 6» и дорожка, где выполненные пункты — `accent`, текущий у идущей сессии пульсирует; без плана — «План ещё не получен».

## Когда использовать
- Внутри `SessionLive` (карточка задачи, экран сессии) и в заголовке списка плана сессии.
- Прогресс по пунктам плана от раннера — не проценты и не время: процентная полоса не используется.
- Шаги мастера формы — `StepIndicator`, маршрут задачи — не здесь.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| done | `number \| null` | обязательный | Выполнено пунктов; `null` — план ещё не получен. |
| total | `number` | `0` | Всего пунктов; 0 — как `null`. |
| live | `boolean` | `false` | Сессия идёт: следующий за выполненными сегмент пульсирует 1,6 с. |
| label | `string` | «План» | Подпись перед числом: «План работы» в заголовке плана. |

## Правила
- Сегмент 4px, радиус `r-xs`, зазор `space-1`; дорожка до 240px, растягивается по месту.
- Выполненные — `accent` (3.3:1 к `surface`, графический элемент), невыполненные — `line-2`; число всегда видно текстом — цвет не единственный носитель смысла.
- Текущий сегмент пульсирует только при `live` и в такт точке «идёт» `SessionLive`; при `prefers-reduced-motion` — `accent-soft` с контуром `accent` без анимации.
- Подпись — `Caption` mono `dim`; для диктора блок — `role="img"` с «План: выполнено 3 из 6».

## Пример
```tsx
import { PlanProgress } from "../index";

<PlanProgress done={3} total={6} live />
<PlanProgress done={null} />
```
