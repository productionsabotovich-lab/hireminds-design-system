# Help

Подпись под полем формы UI 11.5px: подсказка, что вводить, или результат проверки в тоне ошибки или успеха.

## Когда использовать
- Подсказки под полями настроек и онбординга («3–50 символов. Видят агенты и члены команды.»).
- Живая проверка: «совпадает» и «не совпадает» под подтверждением пароля на reset-password, статус проверки API-ключа на BYOK.
- Пояснение под значением бюджета на BYOK.
- Mono-мету делай через Caption, абзац описания через Body. Ошибку, которую Input выводит сам через `error`, не дублируй.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| tone | `"default" \| "error" \| "success"` | `"default"` | Цвет и вес. |
| children | `ReactNode` | обязательный | Текст. |

## Правила
- `font-ui` 11.5px, line-height 1.48, блочный `<span>`.
- default: `mute`, вес 400; error: `danger-ink`, вес 500; success: `accent-ink`, вес 500.
- Не переводи Help в mono и не поднимай до 13px: это уже Caption или Body.
- Держи зазор от поля не меньше 6px, иначе подпись выглядит прилипшей.

## Пример
```tsx
import { Help } from "../index";

<Help>3–50 символов. Видят агенты и члены команды.</Help>
<Help tone="error">не совпадает</Help>
```
