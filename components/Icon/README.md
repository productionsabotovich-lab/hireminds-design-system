# Icon

Набор монохромных иконок 16 и 14 px для объектов продукта и типов файлов; цвет берётся из текста строки.

## Когда использовать
- Рядом с подписью объекта: строка результата (`ResultRow`), раздел «О задаче», ссылка в шапке, шаги сессии, пакет контекста, сводка PR.
- Иконка типа файла — перед именем файла; выбирай её через `iconForFile(path)`, а не вручную.
- Стрелки и шевроны — не здесь, а в `IconArrow`.
- Иконка без подписи рядом не используется: смысл несёт текст, иконка помогает узнать вид.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| name | `IconName` | — | Имя из таблицы ниже. |
| size | `14 \| 16 \| 24` | `16` | Размер в px; 14 — в плотных строках и тексте 12.5–13px; 24 — рядом с заголовком страницы (`EntityRef` `heading`). |
| title | `string` | — | Подпись для диктора. Без неё иконка декоративная (`aria-hidden`). |

Помощник `iconForFile(path: string): IconName` — иконка по имени файла: `*.test.*` и `*.spec.*` → `file-test`, затем расширение; прочее → `file`.

## Правила
- Иконки типов файлов — только 16 px: на 14 px метки `file-md`, `file-yaml`, `file-css` различаются с трудом. 14 px — для объектов продукта в плотных строках.
- Монохром: цвет — `currentColor`, задаёт родитель; в строках — `mute`, в акцентной подписи — `ink`. Цветных подложек и заливок нет.
- Контраст иконки с фоном — не ниже 3:1: `mute` и `ink` проходят на `bg`, `surface`, `bg-2`, `inset`.
- Штрих 1.8 на сетке 24×24, скруглённые концы — в пределах брендбука (1.6–2), рядом с `IconArrow` не спорит.
- Новое имя — правкой этого компонента, не локальным SVG на экране.

## Пример
```tsx
import { Icon, iconForFile } from "../index";

<Icon name="pull-request" />
<Icon name={iconForFile("apps/web/src/members/MembersTable.tsx")} size={14} />
<Icon name="branch" title="Ветка" />
```
