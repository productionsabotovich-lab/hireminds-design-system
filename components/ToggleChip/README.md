# ToggleChip

Чип-переключатель режима: тумблер и подпись в одной кнопке без рамки, `role="switch"` — «Подробно» над лентой «Хода работы».

## Когда использовать
- Режим отображения одного блока, который включают и выключают на месте: «Подробно» в «Ходе работы» сессии.
- Группа взаимоисключающих вкладок — `Switcher`; настройка в форме — поле формы, не чип.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| label | `string` | — | Подпись: «Подробно». |
| pressed | `boolean` | — | Включён: `aria-checked`, тумблер `ink`. |
| onChange | `(pressed: boolean) => void` | — | Новое значение по клику на любой части чипа. |
| hint | `string` | — | Подсказка браузера: что включает режим. |
| disabled | `boolean` | `false` | Недоступен: подпись `mute`, без наведения. |

## Правила
- Без рамки; высота 28px; наведение — фон `bg-2`; фокус — кольцо `accent`.
- Дорожка 24×16px: выключен — `line-3` (3:1 на `surface`), включён — `ink`; бегунок `surface` с тенью `sh-1`, сдвиг без анимации при `prefers-reduced-motion`.
- Подпись не меняется при переключении: состояние читается по тумблеру и `aria-checked`.

## Пример
```tsx
<ToggleChip label="Подробно" pressed={detailed} onChange={setDetailed} hint="Показать вызовы инструментов и вывод" />
```
