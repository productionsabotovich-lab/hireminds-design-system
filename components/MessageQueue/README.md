# MessageQueue

Очередь сообщений в сессию агента над формой: «В очереди к Developer · N» — сообщения, которые дойдут после текущего шага; свёрнута до последнего, «ещё N».

## Когда использовать
- «Сессия агента», состояния «Идёт: три сообщения в очереди» и «Идёт: очередь раскрыта» — в слоте `above` у `CommentForm`.
- Очередь задач агента — попап `AgentStatus`, не здесь.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| role | `string` | — | Кому: «В очереди к Developer». |
| items | `{ id, who, own?, source, time?, text }[]` | — | Сообщения по порядку; пусто — компонент не рисуется. |
| onCancel | `(id) => void` | — | × у своего сообщения: отменить до доставки. |
| defaultOpen | `boolean` | `false` | Раскрыта сразу. |

## Правила
- Шапка — кнопка на `bg-2`: точка `warn` с пульсом, «В очереди к Developer · 3», «дойдут после текущего шага», шеврон.
- Свёрнута: «ещё N сообщений» и последнее сообщение; раскрыта — все.
- Строки — `ListItem` compact: аватар (свои — круглый, агенты — квадратный), текст, «кто · откуда · время».
- × — только у своих сообщений и только до доставки.

## Пример
```tsx
<CommentForm divider={false} above={<MessageQueue role="Developer" items={queue} onCancel={cancel} />} hint="Дойдёт после текущего шага" />
```
