# StageHeader

Крупная шапка stage-блока: зелёный mono-kicker, hero-заголовок 46 или 38px с акцентом и вводный абзац.

## Когда использовать
- aside: левая колонка сплит-лейаута forgot-password («Бывает. Восстановим доступ к команде.»).
- hero: hero-блок пустого дашборда («Найми первого агента.»).
- Над обычной формой и на страницах настроек нужен FormHeader; в модалке своя шапка.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| kicker | `string` | обязательный | Mono-надзаголовок с префиксом «·». |
| heading | `ReactNode` | обязательный | Заголовок; `<em>` выделяет акцент. В aside рендерится `<h1>`, в hero `<h2>`. |
| lead | `ReactNode` | — | Абзац под заголовком. |
| variant | `"aside" \| "hero"` | `"aside"` | Кегль заголовка 46px или 38px. |

## Правила
- Kicker: `font-mono` 11px, вес 500, letter-spacing 0.16em, uppercase, цвет `accent-ink`, с полупрозрачной «·» впереди. Не крась его в `ink` или `mute`.
- Заголовок: `font-display`, вес 600, letter-spacing -0.038em, line-height 1.02, цвет `ink`; `<em>` без курсива цвета `accent-ink`.
- Абзац: `font-ui` 14.5px, цвет `ink-3`, line-height 1.55.
- Вертикальный ритм между частями `space-5` (20px) встроен, свои отступы не добавляй. Так в коде и макетах; прежнее описание `space-9` (36px) у токена исправлено (HIR-50).
- Не заменяй заголовок обычным H1 28px и не убирай kicker.

## Пример
```tsx
import { StageHeader } from "../index";

<StageHeader
  variant="aside"
  kicker="забыли пароль · 1 минута"
  heading={<>Бывает. <em>Восстановим</em> доступ к&nbsp;команде.</>}
  lead="Введи email, на который регистрировался workspace — пришлём ссылку для сброса пароля."
/>
<StageHeader variant="hero" kicker="Шаг 1 из 1 · твой ход" heading={<>Найми первого <em>агента</em>.</>} />
```
