# DiffView

Изменения одного файла — unified diff: номера строк старой и новой версии, добавленные и удалённые строки цветом, фрагменты с заголовком «@@ −14 +14 @@ функция».

## Когда использовать
- Чип файла в «Ходе работы» сессии раскрывает `DiffView` под событием; в режиме «Подробно» — раскрыты все.
- Строка файла в «Изменённых файлах» (`ListItem` `expand`) — тот же `DiffView`.
- Сравнение текстов вне кода (версии документа) — не здесь.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| path | `string` | — | Путь файла — для читалки: «Изменения в apps/web/…». |
| hunks | `{ oldStart, newStart, context?, lines }[]` | — | Фрагменты: строки начинаются с «+», «-» или пробела (unified diff, обычно 3 строки контекста). |
| limit | `number` | `20` | Строк кода до «показать всё (N строк)»; заголовки фрагментов «@@» не считаются. |

## Правила
- Добавленные — фон `accent-soft`, текст `accent-ink`; удалённые — `danger-soft` и `danger-ink`; контекст — `ink-2`; заголовок фрагмента — фон `inset`, `mute`. Только токены.
- Моноширинный 11.5px, номера строк `mute` с цифрами одной ширины, знак и номера не выделяются при копировании.
- Широкие строки не переносятся: блок прокручивается по горизонтали (с клавиатуры — тоже, блок в порядке Tab), страница — нет.
- Для читалки номер строки и знак — словами: «строка 12, добавлено», «строка 15, удалено» (номер новой версии, у удалённой — старой).

## Пример
```tsx
<DiffView
  path="apps/web/src/members/MemberMenu.tsx"
  hunks={[{ oldStart: 14, newStart: 14, context: "export function MemberMenu(…) {", lines: [
    "   const items: MenuItem[] = [];",
    "-  items.push(remove);",
    "+  if (can.removeMember) items.push(remove);",
  ] }]}
/>
```
