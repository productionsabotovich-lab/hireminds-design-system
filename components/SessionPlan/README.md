# SessionPlan

План работы сессии от раннера: заголовок с «N из M» и полосой; выполненные свёрнуты в «Выполнено N», видны текущий и следующий пункт, остальные — «Ещё N пунктов».

## Когда использовать
- «Сессия агента», состояния «Идёт: живой поток» и «Идёт: длинный план, 26 пунктов» — в правой колонке или над лентой.
- Прогресс без пунктов — `PlanProgress`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| items | `{ text, status, added? }[]` | — | Пункты: `status` — `done`, `in_progress`, `interrupted`, `pending`; `added` — метка «добавлен агентом». |
| live | `boolean` | `false` | Сессия идёт: список — живая область (`aria-live="polite"`). |
| defaultOpen | `boolean` | `true` | Список пунктов раскрыт; заголовок сворачивает. |
| empty | `string` | «План появится, когда агент его составит.» | Текст, пока плана нет. |

## Правила
- Пункты — `ListItem` compact в одну строку (32px); иконка состояния в колонке `leading`: `square-check` и `square-dot` — `accent`, `square-dash` (прервано) — `danger`, `square` — `mute`; выполненные — приглушённо; для читалки — «сделано», «в работе», «прервано», «ожидает».
- Заголовки групп «Выполнено N» и «Ещё N пунктов» — одного вида и высоты 32px, иконка в той же колонке, что у пунктов; шаг строк одинаков во всех группах и на 375px.
- План не контейнер: на узкой ширине пункты остаются в одну строку с многоточием, полный текст — в подсказке.

## Пример
```tsx
<SessionPlan live items={[
  { text: "Права в API участников: can()", status: "done" },
  { text: "Тесты прав для каждой роли", status: "in_progress" },
  { text: "Открыть PR", status: "pending" },
]} />
```
