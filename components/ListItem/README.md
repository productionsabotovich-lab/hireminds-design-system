# ListItem

Строка любого списка: `leading` · сущность и название · подпись · состояние · `trailing` · действие — одна сетка на все списки. Живёт только внутри `List`.

## Когда использовать
- Любая строка списка на экранах: решения, сессии ролей, ссылки, результат, очередь, изменённые файлы, проверки (`cells`). Экран не собирает строку своей вёрсткой.
- Заменяет `ListRow` и `ResultRow` (они устарели, см. их README).
- Таблица с колонками и сортировкой — `Table`; журнал событий — `ActivityFeed`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| leading | `ReactNode` | — | Иконка типа (`Icon` 16), аватар (`UserAvatar` xs) или точка; колонка 20px по центру первой строки. |
| leadingTone | `"ink" \| "mute" \| "accent" \| "warn" \| "danger"` | — | Цвет иконки в `leading`. |
| entity | `{ kind, id, hint?, bare? }` | — | `EntityRef` перед названием. |
| title | `ReactNode` | — | Название: одна строка с многоточием; в узкой колонке — до двух строк. |
| path | `string` | — | Путь файла вместо названия: каталог `mute`, имя файла — моно. |
| mono | `boolean` | `false` | Название моноширинным. |
| subtitle / subtitleShort | `ReactNode` | — | Вторая строка; короткая — для узкой колонки (только имя или время). |
| state | `{ tone, label, pulse?, dot? }` | — | Состояние: `Pill` справа; при `emphasis="attention"` — точка и подпись без заливки; в узкой колонке — точка с подписью во второй строке. |
| trailingStart / trailing | `ReactNode` | — | Справа до и после состояния: мета, «+n −m», время. В узкой колонке скрыты. |
| trailingNarrow | `ReactNode` | — | Справа в узкой колонке вместо `trailing`: аватар и точка состояния строки задачи (`TaskSummary` `row`), «+n −m» у файлов, если экрану нужно. По умолчанию — ничего. |
| action | `ReactNode \| "none"` | шеврон / ↗ / ▸▾ | Действие справа, ширина 16px. По умолчанию: шеврон у ссылки, ↗ у новой вкладки, ▸/▾ у раскрытия. |
| href, newTab | `string`, `boolean` | — | Вся строка — ссылка. |
| hint | `string` | — | Подсказка к названию (полный текст). |
| density | `"regular" \| "compact"` | `"regular"` | 44px с разделителями; 32px без разделителей (файлы, проверки). |
| emphasis | `"attention" \| "muted"` | — | Открытое, ждёт действия / закрытое, приглушённо. |
| expand | `{ content, open?, label? }` | — | Вся строка раскрывает содержимое под собой. |
| cells | `boolean` | `false` | Строка в сетке колонок `List grid="cells"`: иконка · название · источник (`badge`) · результат (`trailing`) · действия (`action`, «вывод» из `expand`). |
| badge, resultTone | `ReactNode`, `"danger"` | — | `cells`: источник и тон результата. |

## Правила
- Отступ от `leading` до текста — `space-3` во всех списках; иконка `leading` — по центру первой строки (строка названия 20px).
- Название `font-ui` 13px 500 `ink` (compact — 12.5px), подпись `caption-ui` `mute`; attention — название 400, muted — `mute` 400.
- Наведение и фокус — без заливки: полоса 3px у левого края тоном состояния (`warn`, `accent`, `danger`); закрытые — `mute`, без состояния — `line-3`. Фокус — ещё кольцо `accent` внутри строки.
- Узкая колонка — по ширине `List` (container query: ближайший контейнер — `List`): до 360px название до двух строк, состояние — точкой с подписью во второй строке, справа только действие (`trailingStart`, `trailing` и состояние скрыты; исключение экран задаёт через `trailingNarrow`), каталог пути скрыт; проверки — до 480px: иконка и название, источник и результат, ссылки и «вывод» — тремя строками. Ни одна колонка не сжимается до нуля.
- Действие — фиксированной ширины 16px: правый край один во всех строках.

## Пример
```tsx
import { List, ListItem, UserAvatar } from "../index";

<List title="Решения" count={3}>
  <ListItem href="/decisions/D-44" leading={<UserAvatar name="Антон Саботович" size="xs" shape="circle" />}
    entity={{ kind: "decision", id: "D-44" }} title="Лимит возвратов"
    subtitle="Антон Саботович · ждёт 1 д 2 ч" subtitleShort="ждёт 1 д 2 ч"
    state={{ tone: "warn", label: "Ждёт решения", pulse: true }} emphasis="attention" />
</List>
```
