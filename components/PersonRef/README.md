# PersonRef

Участник команды в тексте — упоминание `@PM`, имя автора или аватар: по наведению, фокусу и нажатию открывается карточка участника.

## Когда использовать
- Упоминания в беседе и комментариях, имя автора решения, аватары участников в шапке беседы.
- Агент — карточка `AgentStatus` (состояние, задача, очередь); человек — аватар, имя-ссылка на профиль, роль, ↗.
- Ссылка на сущность (задача, сессия, решение) — `EntityRef`, не `PersonRef`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| name | `string` | — | Имя или роль: «PM», «Антон Саботович»; ключ в `directory`. |
| human | `boolean` | `false` | Человек, если записи в `directory` нет. |
| directory | `Record<string, { human?, role?, href?, agent?, state?, queue? }>` | — | Справочник участников: человеку — роль и профиль; агенту — данные `AgentStatus` (по умолчанию роль = имя, Claude Code, Sonnet 5.5, свободен). |
| open | `boolean` | `false` | Карточка открыта сразу (состояние макета). |
| children | `ReactNode` | — | Триггер: «@PM», имя, `UserAvatar`. |

## Правила
- Открытие: по наведению мышью через 300 мс, по фокусу с клавиатуры (Tab) сразу, по нажатию (клик, касание, Enter, пробел). Фокус от нажатия мышью карточку сам не открывает — открывает нажатие. На телефоне — только по нажатию.
- Нажатие закрепляет карточку: уход курсора её не закрывает. Нажатие по открытой наведением карточке — закрепляет, по закреплённой — закрывает (как кнопка очереди `AgentStatus`).
- Закрытие: уход курсора с триггера и карточки, если она открыта наведением (через 150 мс — успеть перейти на карточку); Esc (фокус возвращается на триггер); клик вне; повторное нажатие.
- На странице открыта одна карточка: открытие другой закрывает прежнюю. Карточки, открытые пропом `open`, друг друга не закрывают.
- Карточка 300px под триггером; у правого края экрана сдвигается внутрь (отступ 8px).
- Триггер — `role="button"` с `aria-expanded`; карточка — `role="dialog"` с именем участника.

## Пример
```tsx
<p>
  Нужен план кампании —{" "}
  <PersonRef name="PM" directory={team}>@PM</PersonRef>, посмотри бюджет.
</p>
```
