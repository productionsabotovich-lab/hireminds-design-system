# ActivityFeed

Хронологический журнал из записей `ActivityEvent`: в карточке задачи — по дням с переключателем «Сообщения / Вся активность», на экране сессии — лента «Шаги».

## Когда использовать
- `variant="task"` — журнал карточки задачи: заголовки дней «Сегодня», «Вчера», дата; переходы фаз — главы; шаги сессии не выводятся.
- `variant="session"` — лента «Шаги» экрана сессии: без дней, все виды, включая шаги `files`, `check`, `push`, `ask`; в заголовке — `UpdatedAt`.
- Что агент делает прямо сейчас — не строка журнала, а `SessionLive` над ним.
- Список однотипных объектов (решения, сессии) — `ListRow`, не журнал.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| variant | `"task" \| "session"` | `"task"` | Журнал задачи или лента «Шаги». |
| events | `ActivityFeedEvent[]` | обязательный | Пропсы `ActivityEvent` (и необязательный `id` для ключа) в хронологическом порядке; дни компонент строит сам. |
| view | `"messages" \| "all"` | `"all"` | `task`: какие события видны. Без `onViewChange` — начальное значение, переключает сам. |
| onViewChange | `(view) => void` | — | Управляемый переключатель. |
| now | `Date` | текущее время | «Сейчас» для заголовков дней. |
| loading | `boolean` | `false` | `Spinner` на месте журнала, переключатель скрыт. |
| emptyText | `ReactNode` | «Здесь появятся переходы фаз, сессии ролей и решения.» | Текст `EmptyState` «Событий пока нет»: что появится и когда. |
| title | `string` | «Что происходило с задачей» / «Шаги» | Заголовок секции (`SectionHeader`). |
| updatedAt | `Date \| number` | — | `session`: время последнего обновления живой ленты. |

## Правила
- «Сообщения» — `message`, `decision`, `return`, `note`, `reminder`: реплики ролей, решения и их итоги, возвраты, замечания и напоминания платформы. «Вся активность» — ещё `phase`, `session`, `pr`, `error`. По умолчанию — «Вся активность».
- Дни — по местной дате события: «Сегодня», «Вчера», затем «22 октября» (с годом, если год другой); заголовок дня — `Caption` mono `dim` и линия `line`.
- Между днями `space-5`, заголовок и журнал — `space-3`.
- Пусто — `EmptyState` «Событий пока нет» с `emptyText`: что появится и когда. События есть, но в «Сообщениях» пусто — «Сообщений пока нет» и подсказка про «Вся активность». Загрузка — `Spinner` и «Загружаем журнал…».
- Тело ленты в `task` — `role="tabpanel"` с названием выбранного вида.
- Лента — контейнер (`container-type: inline-size`): до 600px ширины ленты записи переходят на узкую раскладку `ActivityEvent`, даже если экран шире.
- События передаются по времени; компонент не сортирует.

## Пример
```tsx
import { ActivityFeed, CodeChip } from "../index";

<ActivityFeed
  now={new Date()}
  events={[
    { id: "e1", kind: "return", time: "2026-10-23T08:42:00+03:00", actor: "QA", children: "вернул задачу в Code",
      detail: "Причина: viewer видит «Удалить участника»" },
    { id: "e2", kind: "phase", time: "2026-10-23T09:14:00+03:00", children: "QA → Code", detail: "Возврат 2 из 2" },
    { id: "e3", kind: "session", time: "2026-10-23T09:14:00+03:00", actor: "Developer",
      children: <>продолжил работу после возврата из QA · <CodeChip href="/sessions/S-118">S-118</CodeChip></> },
  ]}
/>

<ActivityFeed variant="session" updatedAt={Date.now()} events={steps} />
```
