# Spinner

Круглый индикатор загрузки: вращающееся кольцо заданного диаметра, цвет по умолчанию берётся из текста.

## Когда использовать
- Загрузка внутри карточки или на весь экран, например ожидание редиректа после подтверждения email.
- Рядом со строкой статуса процесса.
- Внутри кнопки нужен не Spinner, а `loading` у Button: у неё свой спиннер 13px.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| size | `number` | `18` | Диаметр в px. |
| color | `string` | `"currentColor"` | Цвет кольца: CSS-значение или `var(--token)`. |
| label | `string` | `"Загрузка..."` | aria-label для скринридера (`role="status"`). |

## Правила
- Кольцо толщиной 2px, верхний сегмент прозрачный, оборот за 0.65s линейно.
- Цвет только через токены: `mute` для фоновой загрузки, `accent` для ключевого процесса, `warn` и `danger` для соответствующих статусов; без HEX.
- Задавай осмысленный `label` («Загрузка агентов...»): видимого текста у спиннера нет.
- Размер 14–32px, один спиннер на одну область загрузки.

## Пример
```tsx
import { Spinner } from "../index";

<Spinner />
<Spinner size={24} color="var(--mute)" label="Загрузка агентов..." />
```
