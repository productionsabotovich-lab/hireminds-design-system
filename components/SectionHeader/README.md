# SectionHeader

Заголовок раздела страницы со счётчиком записей и необязательным действием справа.

## Когда использовать
- Над таблицей или списком: «Запуски» и `5`, «События» и `15`, «Фазы» без счётчика.
- Справа — маленькое действие раздела: ExternalLink или Button `sm`.
- Заголовок страницы — H1; заголовок внутри Card — `header` у Card.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| children | `ReactNode` | обязательный | Название раздела: именительный падеж, без двоеточия. |
| count | `number \| string` | — | Число записей справа; `0` тоже выводится. |
| action | `ReactNode` | — | Действие раздела справа от счётчика. |
| level | `2 \| 3` | `2` | Уровень заголовка в структуре документа; вид одинаковый. |

## Правила
- Заголовок как H2 `section`: `font-display` 15px, вес 600, `ink`. Счётчик: `font-mono` 11px `mute`, табличные цифры.
- Заголовок и счётчик стоят на одной базовой линии, счётчик прижат вправо.
- Отступ до содержимого раздела — `space-3` (Stack `gap={3}`).
- Счётчик показывает, сколько записей в разделе сейчас, без слов: «15», а не «15 событий».

## Пример
```tsx
import { SectionHeader } from "../index";

<SectionHeader count={events.length}>События</SectionHeader>
```
