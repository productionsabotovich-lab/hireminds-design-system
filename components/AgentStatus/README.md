# AgentStatus

Виджет агента (вариант A): роль и состояние, задача в работе, раннер и модель, очередь — попапом по «N в очереди ▾».

## Когда использовать
- «Виджет агента» на экранах сессии и задачи, блок «Исполнитель» в «Сессии агента» и «Карточке задачи».
- Карточка агента в `PersonRef` (упоминание `@PM`, аватар роли) — `PersonRef` рисует `AgentStatus` сам.
- Сетка «Моя команда» (плотность `row`) — позже, отдельной заявкой.
- «Ждёт решения» у агента нет: решения ждёт задача (`TaskSummary`, «Решения»).

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| agent | `{ role, runner, model, connection? }` | — | Роль — имя и аватар; раннер и модель — нижняя строка; подключение — в подсказке модели. |
| state | `AgentState` | — | `{ kind: "working", task: { key, title, href?, phase?, plan?: { done, total } } }` · `{ kind: "free" }` · `{ kind: "error", title, until?, fix? }` · `{ kind: "paused", since, by }` · `{ kind: "off", fix? }`. `fix` — строка или `{ text, cmd }` (команда — `CodeChip`). |
| queue | `{ key, title, href?, current?, waited?, priority? }[]` | `[]` | Очередь: текущая задача (`current`) и ждущие. Кнопка «N в очереди» — по числу ждущих. |
| queueOpen | `boolean` | `false` | Попап очереди открыт сразу (состояние макета). |
| agentHref | `string` | — | Карточка агента: имя роли и ↗. |

## Правила
- Первая строка: аватар роли (квадратный), имя роли — ссылка в карточку агента, состояние точкой с подписью, справа ↗ с подсказкой «Открыть карточку агента».
- Состояния: `working` — «Работает», точка `accent` с пульсом и строка задачи (`EntityRef` и название; вся строка — ссылка; полное название, фаза и план — в подсказке); `free` — только «Свободен» и модель; `error` — рамка `danger`, плашка `danger-soft` с причиной, «Восстановится в 18:00 · задачи ждут в очереди» и командой; `paused` — «Пауза с 14:20, поставил …»; `off` — «Не подключён» и как подключить.
- Очередь — попап поверх страницы, высота виджета не меняется. От левого края кнопки, ширина по содержимому 360–480px, на узком экране — не шире экрана без 16px с каждой стороны; у правого края сдвигается внутрь. Внутри — `List` «Очередь PM · 1 ждёт», строки в одну строку, текущая отмечена точкой, справа приоритет.
- Попап закрывается кликом вне, Esc (фокус возвращается на кнопку), повторным нажатием и прокруткой колонки с виджетом. На странице открыт один: открытие другой очереди закрывает прежнюю.
- Esc в попапе очереди внутри карточки `PersonRef` закрывает только очередь.

## Пример
```tsx
<AgentStatus
  agent={{ role: "PM", runner: "Claude Code", model: "Sonnet 5.5" }}
  state={{ kind: "working", task: { key: "PIL-15", title: "Роли участников проекта", href: "/tasks/PIL-15", phase: "Code", plan: { done: 3, total: 7 } } }}
  queue={[
    { key: "PIL-15", title: "Роли участников проекта", current: true, priority: "high" },
    { key: "PIL-22", title: "Экспорт отчёта QA в PDF", waited: "2 ч", priority: "urgent" },
  ]}
  agentHref="/agents/pm"
/>
```
