# CommentForm

Комментарий к задаче под журналом: многострочное поле с подсказкой упоминаний на «@» (роли и специалисты), подпись «куда попадёт комментарий» и главная кнопка «Отправить».

## Когда использовать
- Карточка задачи — под журналом (`ActivityFeed`): комментарий уходит в журнал и в тред трекера.
- Упоминание «@Developer» адресует комментарий роли-агенту, «@Анна Петрова» — специалисту; ответ роли на упоминание — итерация 3.
- Роли — любые названия из workflow проекта; список упоминаний собирает платформа, компонент названий не знает.
- Не здесь: сообщение в «Сессии агента» — `SessionComposer`, без упоминаний; причина возврата или остановки на странице решения — `Textarea` и две кнопки в блоке действий.
- Без `mentions` форма — обычное поле с кнопкой: ни подсказки, ни «@» в тексте-подсказке.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| id | `string` | `"comment"` | id поля; от него — id списка упоминаний и пунктов. |
| value | `string` | — | Текст. Без него форма хранит текст сама и очищает его после отправки. |
| onChange | `(value: string) => void` | — | Изменение текста, в том числе подстановка упоминания. |
| placeholder | `string` | с `mentions` — «Напишите комментарий; @ — упомянуть роль или специалиста», без — «Напишите комментарий» | Подсказка в пустом поле. |
| mentions | `CommentMention[]` | `[]` | Кого можно упомянуть: `{ name, kind: "role" \| "person", caption?, image? }`. |
| onSubmit | `(text: string) => void \| Promise` | — | Отправка: текст без пробелов по краям. Вернёт `Promise` — без `value` текст очистится, когда он выполнится; при отказе текст останется. |
| loading | `boolean` | `false` | Идёт отправка: поле и кнопка недоступны, на кнопке — загрузка. |
| error | `string` | — | Ошибка отправки под полем (`role="alert"`); текст в поле не трогается. |
| label | `string` | «Комментарий» | Подпись поля. |
| hint | `string` | «Комментарий попадает в журнал и в тред Linear» | Подпись у кнопки. |

`CommentMention`: `name` — название роли или имя специалиста; `kind` — `role` (роль-агент) или `person` (специалист-человек);
`caption` — подпись в подсказке, по умолчанию «роль» или «специалист»; `image` — аватар специалиста.

## Правила
- Подсказка открывается там, где курсор: перед курсором «@» в начале текста или после пробела и, может быть, начало имени («@», «@Dev»), а за курсором — конец текста или пробел. Упоминание можно вставить в середину уже набранного текста.
- Фильтр — по началу любого слова имени («@петр» → «Анна Петрова») или по началу подписи («@спец» → все специалисты), без учёта регистра, кириллица и латиница. Совпадений нет — подсказка закрыта.
- Выбор заменяет «@» и набранное начало на «@Имя» с пробелом и ставит курсор сразу за ним; текст после курсора остаётся на месте. Имя, набранное целиком, и отправка подсказку закрывают.
- Пункт подсказки: аватар `UserAvatar` (роль — `shape="square"` с инициалами, специалист — `shape="circle"`, фото из `image`), имя `ink` 12px, подпись `mute` 11.5px.
- **Клавиатура.** Пока подсказка открыта: ↓ и ↑ — по пунктам, после последнего — снова первый; Enter или Tab — выбрать; Esc — закрыть до следующего изменения текста; Shift+Tab — уйти из поля. Ctrl+Enter или ⌘+Enter — отправить, в том числе при открытой подсказке. Без подсказки Enter переносит строку.
- Ввод через IME (составление символа): Enter, Tab и Ctrl/⌘+Enter не выбирают и не отправляют.
- Уход фокуса из поля подсказку закрывает; мышью пункт выбирается по нажатию (`mousedown`), фокус остаётся в поле.
- Для диктора поле — `role="combobox"` с `aria-autocomplete="list"`, `aria-controls` на список, `aria-expanded` и `aria-activedescendant` на активный пункт; список — `role="listbox"` (в DOM всегда, закрытый — `hidden`), пункты — `role="option"` с `aria-selected`.
- Подсказка — над полем: `surface`, рамка `line`, `r-md`, тень `sh-2`; активный пункт — фон `bg-2`.
- Умеренный монохром: цвет только у главной кнопки `ink`. Пустой комментарий не отправляется — кнопка недоступна.
- Узкая форма (до 420px по ширине самой формы) — кнопка на всю ширину.

## Пример
```tsx
import { CommentForm } from "../index";

<CommentForm
  id="task-comment"
  mentions={[
    { name: "Developer", kind: "role" },
    { name: "Reviewer", kind: "role" },
    { name: "Анна Петрова", kind: "person", image: avatarUrl },
  ]}
  loading={sending}
  error={sendError}
  onSubmit={(text) => sendComment(task.id, text)}
/>
```
