# CommentForm

Комментарий к задаче под журналом: многострочное поле с подсказкой ролей на «@», подпись «куда попадёт комментарий» и главная кнопка «Отправить».

## Когда использовать
- Карточка задачи — под журналом (`ActivityFeed`): комментарий уходит в журнал и в тред Linear.
- Упоминание роли «@Developer» — адресует комментарий роли; ответ роли на упоминание — итерация 3.
- Причина возврата или остановки на странице решения — не здесь: там `Textarea` и две кнопки в блоке действий.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| id | `string` | `"comment"` | id поля; от него — id списка ролей и пунктов. |
| value | `string` | — | Текст. Без него форма хранит текст сама и очищает его после отправки. |
| onChange | `(value: string) => void` | — | Изменение текста, в том числе подстановка роли. |
| placeholder | `string` | «Напишите комментарий; @ — упомянуть роль» | Подсказка в пустом поле. |
| mentions | `string[]` | `[]` | Роли проекта для подсказки на «@». |
| onSubmit | `(text: string) => void` | — | Отправка: текст без пробелов по краям. |
| loading | `boolean` | `false` | Идёт отправка: поле и кнопка недоступны, на кнопке — загрузка. |
| label | `string` | «Комментарий» | Подпись поля. |
| hint | `string` | «Комментарий попадает в журнал и в тред Linear» | Подпись у кнопки. |

## Правила
- Подсказка открывается, когда текст заканчивается на «@» и, может быть, начало роли: «@», «@Dev». Роли фильтруются по началу имени без учёта регистра; выбор подставляет «@Developer » с пробелом. Роль, набранная целиком, и отправка подсказку закрывают.
- **Клавиатура.** Пока подсказка открыта: ↓ и ↑ — по ролям по кругу, Enter или Tab — выбрать активную роль, Esc — закрыть подсказку до следующего изменения текста. Без подсказки Enter переносит строку, Ctrl+Enter или ⌘+Enter — отправить.
- Для диктора поле — `role="combobox"` с `aria-controls` на список, `aria-expanded` и `aria-activedescendant` на активный пункт; список — `role="listbox"`, пункты — `role="option"` с `aria-selected`.
- Мышью роль выбирается по нажатию (`mousedown`): фокус остаётся в поле.
- Подсказка — над полем: `surface`, рамка `line`, `r-md`, тень `sh-2`; пункт — аватар роли и имя `ink` 12px, активный — фон `bg-2`.
- Умеренный монохром: цвет только у главной кнопки `ink`. Пустой комментарий не отправляется — кнопка недоступна.
- Узкая форма (до 420px по ширине самой формы) — кнопка на всю ширину.

## Пример
```tsx
import { CommentForm } from "../index";

<CommentForm
  id="task-comment"
  mentions={["Analyst", "Developer", "Reviewer", "QA"]}
  loading={sending}
  onSubmit={(text) => sendComment(task.id, text)}
/>
```
