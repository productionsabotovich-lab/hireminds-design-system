# SessionLive

Что агент делает прямо сейчас: в карточке задачи — закреплённая ссылка в «Сессию агента» с ролью, статусом, планом и текущей операцией; на экране сессии — строка «Сейчас».

## Когда использовать
- `variant="widget"` — карточка задачи (в итерации 3 — карточка агента и «Моя команда»): над журналом под шапкой, пока сессия идёт; закреплён вместе с карточкой решения, решение выше сессии. По завершении исчезает — итог остаётся строкой журнала (`ActivityEvent`).
- `variant="now"` — экран сессии. **Заглушка:** состояния уточняются макетом «Сессия агента» (HIR-32); API зафиксирован, вид может измениться.
- Завершённые сессии — `ListRow` в списке «Сессии ролей», не `SessionLive`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| variant | `"widget" \| "now"` | `"widget"` | Виджет-ссылка или строка «Сейчас». |
| status | `"running" \| "starting" \| "answering" \| "retrying"` | `"running"` | «идёт»; «идёт» без плана; «отвечает» на вопрос после шага; «повтор» после технической ошибки. |
| role | `string` | обязательный | Роль: аватар и заголовок «Developer · сессия S-118». |
| sessionId | `string` | обязательный | Идентификатор сессии. |
| href | `string` | — | Ссылка в «Сессию агента»; widget целиком — ссылка. |
| resumed | `"transcript" \| "no-transcript" \| null` | `null` | «Возобновлена»; «Возобновлена без транскрипта» — выделено; `null` — «Идёт». |
| plan | `{ done, total, current? } \| null` | `null` | План от раннера — `PlanProgress`; `current` — название текущего пункта (now). |
| operation | `ReactNode` | обязательный | Текущая операция одной фразой: «запускает проверки проекта». |
| detail | `string` | — | now: технический хвост операции — `CodeChip` sm. |
| since | `Date \| number \| string` | обязательный | Начало работы; время выводится «менее минуты», «23 мин», «1 ч 05 мин». |
| loading | `boolean` | `false` | «обновляется» вместо времени, пока идёт запрос. |

## Правила
- Статус — точка `Dot` `ink` с пульсом и подпись `ink-2`: умеренный монохром, живое не красится в `accent`. `warn` (точка и подпись `warn-ink`) — только у `retrying`. В утверждённом макете здесь `Pill accent`: отступ по правилу задачи HIR-42 «живая точка `ink`».
- Пульс точки и текущего сегмента плана — 1,6 с; при `prefers-reduced-motion` анимации нет.
- widget: `surface`, рамка `line`, `r-lg`, `sh-1`, паддинг `space-3` `space-4`, до 560px (в закреплённой зоне — на ширину колонки). Наведение — рамка `line-2` и фон `bg`, стрелка сдвигается на 2px; фокус — кольцо `accent`.
- Виджет уже 420px (container query по обёртке; на телефоне 375 — 343px) — аватар скрыт: роль уже названа в заголовке; план и операция — на всю ширину. Обёртка — до 560px; в закреплённой зоне экрана ей задаётся ширина колонки.
- `aria-label` ссылки называет роль, сессию, статус, план и операцию: «Developer, сессия S-118, идёт, план 3 из 6. Сейчас: …».
- Время пересчитывается при каждом рендере: платформа обновляет виджет вместе с данными сессии.

## Пример
```tsx
import { SessionLive } from "../index";

<SessionLive
  role="Developer"
  sessionId="S-118"
  href="/sessions/S-118"
  resumed="transcript"
  since={session.wokeAt}
  plan={{ done: 3, total: 6 }}
  operation="скрывает действия по роли в таблице, меню и карточке участника"
/>
```
