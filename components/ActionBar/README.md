# ActionBar

Главные действия решения: вопрос и задача слева, кнопки в один ряд справа; `bar` — полоса, закреплённая внизу экрана, `block` — блок «Ваше решение» на странице того же вида.

## Когда использовать
- «Страница решения»: блок «Ваше решение» (`block`) в содержимом и полоса (`bar`) внизу экрана, пока блок не виден.
- Состояние «ввод причины» («Укажите причину») — поле причины рядом с блоком, кнопки те же.
- Сохранение формы настроек — не здесь (заявка SaveBar).

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| question | `string` | — | Вопрос решения жирным: «Утвердить план кампании?». |
| summary | `string` | — | Задача и контекст после вопроса: «D-46 · PIL-31 · бюджет 95 000 ₽». |
| actions | `{ label, variant?, onSelect?, loading?, disabled? }[]` | — | Кнопки по порядку: основная — первой, левее. |
| variant | `"bar" \| "block"` | `"bar"` | `bar` — закреплена внизу (sticky), `role="region"` «Действия решения»; кнопки — дубль блока, вне порядка Tab (`tabIndex=-1`), но доступны читалке и мыши; `block` — «Ваше решение» на странице, `role="region"`. |

## Правила
- Одна строка: слева вопрос и задача с многоточием (полный текст — в подсказке), справа кнопки по ширине подписи.
- Контейнер до 600px: вопрос сверху (переносится), кнопки в один ряд поровну на всю ширину; длинная подпись переносится на две строки внутри кнопки (на 320px — и при трёх кнопках). Друг под другом кнопки не встают никогда.
- `position: sticky` работает, только если полоса — прямой потомок прокручиваемой колонки (или её содержимого без своего `overflow`).
- Хост — во всю ширину (`width: 100%`, контейнер `inline-size`): в flex-ряду и auto-колонке не схлопывается.
- `bar`: фон `surface`, рамка сверху `line`, тень `sh-2`, отступ снизу учитывает safe-area телефона. На странице всегда есть `block` с теми же действиями — полоса его только дублирует.

## Пример
```tsx
const actions = [
  { label: "Утвердить", variant: "primary", onSelect: approve },
  { label: "Вернуть на доработку", variant: "secondary", onSelect: askReason },
];
<ActionBar variant="block" question="Утвердить план кампании?" summary="D-46 · PIL-31" actions={actions} />
<ActionBar variant="bar" question="Утвердить план кампании?" summary="D-46 · PIL-31" actions={actions} />
```
