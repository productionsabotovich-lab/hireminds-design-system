# UserAvatar

Аватар человека или агента: фото или инициалы на зелёном градиенте или сплошном цвете, круг или квадрат.

## Когда использовать
- Круг с `accent`: текущий пользователь — меню аккаунта в топбаре (lg), футер sidebar (md), меню онбординга (sm).
- Квадрат со сплошным цветом: один из многих — строки таблицы команды (md), список агентов в sidebar (xs), карточки approval (sm).
- Логотип workspace и марка H делаются через Brand, а не UserAvatar.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| name | `string` | обязательный | Полное имя: из него берутся до 2 инициалов (запасной вариант «U»), оно же aria-label. |
| image | `string \| null` | — | URL фото; если задан, выводится вместо инициалов. |
| size | `"xs" \| "sm" \| "md" \| "lg"` | `"sm"` | 18 / 24 / 28 / 32px. |
| shape | `"circle" \| "square"` | `"square"` | Круг 999px или квадрат с радиусом `r-sm`. |
| color | `"accent" \| string` | `"accent"` | accent: градиент; любое другое значение — сплошная заливка CSS-цветом или `var(--token)`. |

## Правила
- Инициалы: `font-display`, вес 600, цвет `#fff`; кегль 9.5 / 10.5 / 11.5 / 12px по размерам.
- Градиент `accent` (от `accent` к `accent-2`, без бирюзы — её запрещает брендбук) только у текущего пользователя; остальным сплошные `ink`, `ink-2` или `mute`.
- Для сплошного цвета передавай токен (`var(--mute)`, `var(--ink-2)`), а не произвольный HEX.
- Круг означает «мой аккаунт», квадрат (`r-sm`, 5px) означает «один из многих»; радиус 8px не ставь.

## Пример
```tsx
import { UserAvatar } from "../index";

<UserAvatar name="Антон Саботович" size="lg" shape="circle" />
<UserAvatar name="Катя Смирнова" size="md" color="var(--mute)" />
```
