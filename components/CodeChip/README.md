# CodeChip

Короткое значение кода в тексте и в строках — коммит, ветка, путь, команда, идентификатор; может быть ссылкой на экран или в GitHub.

## Когда использовать
- Значения, которые человек копирует или узнаёт по виду: `a41f9c2`, `hm/PIL-15-project-roles`, `apps/web/src/members/roles.ts`, `hm runner connect`, `S-118`, `D-44`.
- Ссылка на объект по его идентификатору: сессия, решение, коммит или ветка в GitHub.
- Не для выбираемых тегов (это паттерн Chip) и не для статусов (Pill).
- Не для многострочного кода и вывода — это `TerminalBox`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| children | `ReactNode` | — | Значение как есть, без сокращений и смены регистра. |
| href | `string` | — | Делает чип ссылкой; без него чип статичный. |
| newTab | `boolean` | `false` | Открывает ссылку в новой вкладке (GitHub, Linear). |
| title | `string` | — | Подсказка при наведении: полный путь или смысл значения. |
| size | `"md" \| "sm"` | `"md"` | `md` — 12px; `sm` — 10.5px для `Caption` и строк меты. |

## Правила
- Вид по основам: `font-mono` на `inset`, радиус `r-xs`, текст `ink-2`; цвета нет — монохром.
- Кегль из шкалы моно-меток: `md` — 12px в тексте и строках, `sm` — 10.5px в `Caption` и строках меты. В `Caption` капитель на чип не действует.
- Длинное значение переносится по символам, а не обрезается: путь виден целиком даже в узкой колонке.
- Ссылка: подчёркивание `ink-3`, при наведении `ink`; фокус с клавиатуры — кольцо `accent`, как во всей системе.
- Контраст: `ink-2` на `inset` — выше 4.5:1; подчёркивание `ink-3` на `inset` — выше 3:1 (`line-3` там даёт 2.8:1).

## Пример
```tsx
import { CodeChip } from "../index";

<CodeChip>a41f9c2</CodeChip>
<CodeChip href="/sessions/S-118" title="Сессия агента S-118">S-118</CodeChip>
<CodeChip href="https://github.com/org/repo/tree/hm/PIL-15-project-roles" newTab>hm/PIL-15-project-roles</CodeChip>
```
