# Divider

Разделительная линия 1px: горизонтальная, вертикальная или с mono-подписью по центру вроде «или email».

## Когда использовать
- С `label`: между SSO-кнопками и email-формой на signin и create-account («или email»).
- `dashed`: между строками внутри секции и перед ссылками под карточкой email-sent.
- `strong`: над закреплённым рядом действий онбординга; `vertical`: между колонками сплит-карточки на дашборде.
- Если элементы уже разведены gap, Divider не нужен. Точка между ссылками футера — Dot `variant="separator"`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| orientation | `"horizontal" \| "vertical"` | `"horizontal"` | Ориентация; при `label` не учитывается. |
| weight | `"subtle" \| "strong" \| "dashed"` | `"subtle"` | subtle: сплошная `line`; strong: сплошная `line-2`; dashed: пунктир `line-2`. |
| label | `string` | — | Подпись по центру; превращает разделитель в ряд «линия — подпись — линия». |

## Правила
- Толщина всегда 1px, цвет только `line` или `line-2`: без 2–3px и без HEX.
- С подписью: текст `font-mono` 10px, вес 500, letter-spacing 0.1em, uppercase, цвет `dim`; gap 12px; встроенные отступы 6px сверху и 18px снизу, свои не добавляй.
- Пунктир означает слабую связь подсекций; главный разделитель пунктиром не делай.
- Не ставь двойные разделители сверху и снизу одного элемента.

## Пример
```tsx
import { Divider } from "../index";

<Divider label="или email" />
<Divider weight="dashed" />
```
