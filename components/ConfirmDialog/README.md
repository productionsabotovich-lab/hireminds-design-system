# ConfirmDialog

Модальное окно подтверждения необратимого действия: вопрос, последствие и две кнопки, фокус — на безопасной.

## Когда использовать
- Перед действием, которое нельзя откатить из интерфейса: «Отменить запуск?», «Удалить workspace?».
- Обратимые действия («Повторить», «Обновить») выполняй сразу, без окна.
- Не для форм и не для сообщений об ошибке: ошибку после действия показывай Plate на странице.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| open | `boolean` | обязательный | Показано ли окно; компонент контролируемый. |
| title | `string` | обязательный | Вопрос с действием и объектом: «Отменить запуск?». |
| children | `ReactNode` | — | Последствие в 1–2 предложения. |
| confirmLabel | `string` | обязательный | Глагол действия из заголовка: «Отменить». |
| cancelLabel | `string` | `"Назад"` | Безопасный выход. |
| tone | `"default" \| "danger"` | `"default"` | danger — красная кнопка подтверждения. |
| loading | `boolean` | `false` | Запрос идёт: спиннер на подтверждении, кнопки неактивны, Escape не закрывает. |
| onConfirm | `() => void` | обязательный | Подтверждение. |
| onCancel | `() => void` | обязательный | Отказ: кнопка, Escape, клик по фону. Запрос не отправляется. |

## Правила
- Панель: `surface`, радиус `r-xl`, тень `sh-3`, паддинг `space-6`, ширина до 400px; фон-затемнение — `ink` 32%.
- Заголовок `font-display` 17px `ink`, текст 13px `ink-3`; кнопки справа, gap `space-2`: сначала отмена (secondary), затем подтверждение.
- При открытии фокус на кнопке отмены, Tab не выходит из окна, после закрытия фокус возвращается.
- Текст кнопки подтверждения — глагол из заголовка («Отменить»), не «Да» и не «ОК».

## Пример
```tsx
import { ConfirmDialog } from "../index";

<ConfirmDialog open={asking} tone="danger" title="Отменить запуск?" confirmLabel="Отменить"
  onConfirm={cancelRun} onCancel={() => setAsking(false)}>
  Статус issue в трекере не изменится.
</ConfirmDialog>
```
