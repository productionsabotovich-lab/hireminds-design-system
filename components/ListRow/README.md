# ListRow

Строка списка в боковой колонке: аватар, название с идентификатором, одно состояние справа и вторая строка — кликабельна целиком, без кнопки «Открыть».

## Когда использовать
- Короткие списки сбоку: «Решения» и «Сессии ролей» в карточке задачи, списки на «Главной проекта».
- Строки собираются в список по рецепту ниже; пустой список — `EmptyState mini` с объяснением, например «Решений пока нет».
- Артефакты задачи (PR, файлы, отчёты) — не здесь, а в `ResultRow`.

### Граница с Table
| ListRow | Table |
|---|---|
| узкая колонка, 3–10 строк | основная колонка, много строк |
| одно состояние и вторая строка текста | несколько колонок значений |
| без сортировки и заголовков колонок | заголовки, сортировка, выравнивание чисел |
| карточка задачи, «Главная проекта» | «Мои решения», журналы и реестры |

### Как собрать список
Как в макете «Карточка задачи»: заголовок `SectionHeader level={3}` с числом строк над рамкой, рамка — `1px solid line`,
радиус `r-lg`, фон `surface`, `overflow: hidden`, без внутренних отступов. Строки кладутся прямо в рамку и заполняют её
от края до края; разделитель `line` между соседними строками `ListRow` рисует сам. Пустой список — `EmptyState mini`
под заголовком вместо рамки.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| href | `string` | — | Вся строка — ссылка, справа шеврон; без него строка статичная, без шеврона. |
| newTab | `boolean` | `false` | Открывает ссылку в новой вкладке. |
| lead | `ReactNode` | — | Слева: обычно `UserAvatar size="xs"`. |
| title | `string` | — | Название: гейт решения, роль сессии. |
| code | `string` | — | Идентификатор рядом с названием — `CodeChip`: `D-44`, `S-118`. |
| trailing | `ReactNode` | — | Справа одно состояние — `Pill`. |
| sub | `ReactNode` | — | Вторая строка `mute`: кто, когда, канал, длительность. |

## Правила
- Цвет только у `Pill` состояния; название `ink`, вторая строка `mute`.
- Строка-ссылка: справа шеврон `IconArrow chevron` 12 px `dim`, при наведении — `ink` и сдвиг на 2 px; наведение строки — фон `inset`, фокус — рамка `accent` и кольцо `accent-soft`, как у `Input`.
- Идентификатор внутри строки-ссылки — статичный `CodeChip`: ссылка в ссылке недопустима.
- Статичная строка — когда перехода нет, а объект надо показать: например, решение без своей страницы.
- Название и идентификатор идут одним потоком: чип встаёт за последним словом и не переносится по символам. Состояние и шеврон остаются справа.
- `lead`, `trailing`, `sub` со значением `null` не рисуются: колонка аватара схлопывается.

## Пример
```tsx
import { ListRow, Pill, SectionHeader, UserAvatar } from "../index";

<SectionHeader level={3} count={2}>Решения</SectionHeader>
<div className={styles.list /* рамка line, r-lg, surface, overflow: hidden */}>
  <ListRow
    href="/decisions/D-44"
    lead={<UserAvatar name="Антон Саботович" size="xs" shape="circle" />}
    title="Лимит возвратов"
    code="D-44"
    trailing={<Pill tone="warn" dot>Ждёт решения</Pill>}
    sub="Антон Саботович · ждёт 1 д 2 ч"
  />
  <ListRow href="/decisions/D-21" title="Объём согласован" code="D-21" trailing={<Pill tone="accent">Утверждено</Pill>} sub="кнопка в треде" />
</div>
```
