# ListRow

Строка списка в боковой колонке: аватар, название с идентификатором, одно состояние справа и вторая строка — кликабельна целиком, без кнопки «Открыть».

## Когда использовать
- Короткие списки сбоку: «Решения» и «Сессии ролей» в карточке задачи, списки на «Главной проекта».
- Строки собираются в `Card` (рамка на `surface`); пустой список — `EmptyState mini` с объяснением, например «Решений пока нет».
- Артефакты задачи (PR, файлы, отчёты) — не здесь, а в `ResultRow`.

### Граница с Table
| ListRow | Table |
|---|---|
| узкая колонка, 3–10 строк | основная колонка, много строк |
| одно состояние и вторая строка текста | несколько колонок значений |
| без сортировки и заголовков колонок | заголовки, сортировка, выравнивание чисел |
| карточка задачи, «Главная проекта» | «Мои решения», журналы и реестры |

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| href | `string` | — | Вся строка — ссылка; без него строка статичная. |
| newTab | `boolean` | `false` | Открывает ссылку в новой вкладке. |
| lead | `ReactNode` | — | Слева: обычно `UserAvatar size="xs"`. |
| title | `string` | — | Название: гейт решения, роль сессии. |
| code | `string` | — | Идентификатор рядом с названием — `CodeChip`: `D-44`, `S-118`. |
| trailing | `ReactNode` | — | Справа одно состояние — `Pill`. |
| sub | `ReactNode` | — | Вторая строка `mute`: кто, когда, канал, длительность. |

## Правила
- Цвет только у `Pill` состояния; название `ink`, вторая строка `mute`.
- Строка-ссылка: наведение — фон `inset`, фокус — рамка `accent` и кольцо `accent-soft`, как у `Input`.
- Идентификатор внутри строки-ссылки — статичный `CodeChip`: ссылка в ссылке недопустима.
- Статичная строка — когда перехода нет, а объект надо показать: например, решение без своей страницы.
- На узком экране название и идентификатор переносятся, состояние остаётся справа.

## Пример
```tsx
import { Card, ListRow, Pill, UserAvatar } from "../index";

<Card header="Решения">
  <ListRow
    href="/decisions/D-44"
    lead={<UserAvatar name="Антон Саботович" size="xs" shape="circle" />}
    title="Лимит кругов"
    code="D-44"
    trailing={<Pill tone="warn" dot>ждёт</Pill>}
    sub="Антон Саботович · ждёт 1 д 2 ч"
  />
</Card>
```
