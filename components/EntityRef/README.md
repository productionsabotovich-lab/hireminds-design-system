# EntityRef

Идентификатор сущности с иконкой своего типа — задача, сессия, решение, PR, коммит, прогон CI, документ: моноширинный ключ, необязательное название и ссылка.

## Когда использовать
- Везде, где упоминается сущность продукта: шапки экранов, хлебные крошки, строки списков, лента, «Мои решения», беседа.
- Вместо `TaskRef`: `TaskRef` — это `EntityRef` `kind="task"` (см. README `TaskRef`).
- Ветка — `BranchRef`; файл с путём и счётчиком — `ResultRow`; код и команда без сущности — `CodeChip`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| kind | `"task" \| "session" \| "decision" \| "pr" \| "commit" \| "ci" \| "doc"` | обязательный | Тип: иконка (`tracker`, `session`, `decision`, `pull-request`, `commit`, `workflow`, `file`) и слово для читалки. |
| id | `string` | обязательный | Ключ моноширинным: «PIL-15», «S-118», «D-44», «#21», «a4b23ec». |
| title | `string` | — | Название после ключа. |
| href | `string` | — | Ссылка; без неё — текст. |
| newTab | `boolean` | `false` | Новая вкладка (трекер, GitHub); после текста — ↗. |
| size | `"inline" \| "title" \| "heading"` | `"inline"` | `inline` — кегль родителя, иконка 14px; `title` — заголовок виджета 13.5px / 18px, иконка 16px; `heading` — рядом с заголовком страницы, кегль родителя, иконка 24px. |
| bare | `boolean` | `false` | Без иконки: иконка уже в колонке `leading` строки. |
| hint | `string` | — | Подсказка `Tooltip`: «Открыть в GitHub». В размере `title` к ней добавляется полное название. |
| truncate | `boolean` | `false` | Одна строка с многоточием в кегле родителя: строка задачи в `AgentStatus`. |

## Правила
- Иконка — в коробке высотой в строку текста (`1lh`), поэтому стоит по центру **первой** строки при любом кегле; отклонение центра — не больше 1px (замерено в превью во всех размерах).
- `bare` убирает только иконку: текст остаётся на той же линии, что и с иконкой.
- `title`: название — в одну строку с многоточием, полный «ключ название» — в `Tooltip`, только если обрезано. `heading`: название переносится, иконка — по первой строке, ключ `mute` 500.
- Ключ — `font-mono` 0.92em `ink-2`, название — `ink`, иконка и ↗ — `mute`. Наведение на ссылку — подчёркивание `line-3`, фокус — кольцо `accent`.
- Для читалки перед ключом — тип: «задача PIL-15», «сессия S-118».

## Пример
```tsx
import { EntityRef } from "../index";

<EntityRef kind="task" id="PIL-15" href="/tasks/PIL-15" />
<EntityRef kind="session" id="S-118" title="Developer" size="title" href="/sessions/S-118" />
<h1><EntityRef kind="decision" id="D-46" title="Утверждение плана кампании" size="heading" /></h1>
<EntityRef kind="pr" id="#21" href={prUrl} newTab hint="Открыть в GitHub" />
```
