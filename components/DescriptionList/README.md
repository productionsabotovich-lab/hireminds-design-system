# DescriptionList

Сводка записи: пары «подпись — значение» в сетке из 1–4 колонок, подпись капителью над значением.

## Когда использовать
- Шапка карточки записи: сводка запуска (состояние, фаза, роль, круг, в фазе), реквизиты проекта.
- Значение может быть компонентом: Pill для состояния, ExternalLink для ссылки.
- Много однотипных записей — Table; длинный текст — Body в Card.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| items | `DescriptionItem[]` (`{ label, value, mono? }`) | обязательный | Пары; `mono` — Geist Mono для ключей, времени и чисел. |
| columns | `1 \| 2 \| 3 \| 4` | `4` | Колонки на широком экране; до 720px — 2, до 420px — 1. |

## Правила
- Семантика `dl` / `dt` / `dd`. Gap `space-4` по вертикали и `space-6` по горизонтали, внутри пары — `space-1`.
- Подпись: `font-mono` 10.5px uppercase, трекинг .06em, `mute`. Значение: `font-ui` 13.5px `ink`; `mono` — 12.5px.
- Подписи — существительные без двоеточия: «Фаза», «Круг», «В фазе».
- Пустое значение — «—», не пропуск пары: сетка не должна прыгать между записями.

## Пример
```tsx
import { DescriptionList, Pill } from "../index";

<DescriptionList items={[
  { label: "Состояние", value: <Pill tone="danger" dot>Блокер</Pill> },
  { label: "Фаза", value: "Review" },
  { label: "Круг", value: "2", mono: true },
]} />
```
