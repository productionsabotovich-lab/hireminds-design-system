# Textarea

Многострочное поле: подпись, поле на несколько строк, под ним подсказка или ошибка и счётчик символов — многострочный аналог `Input` и `Field`.

## Когда использовать
- Свободный текст длиннее одной строки: причина возврата или остановки на странице решения, комментарий к задаче (внутри `CommentForm`).
- Короткое значение в одну строку — `Input` или `Field`.
- Подсказка ролей на «@» и кнопка отправки — не здесь, а в `CommentForm`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| id | `string` | — | Связывает подпись, подсказку, ошибку и счётчик с полем. |
| label | `string` | — | Подпись над полем. |
| value | `string` | — | Значение; без него поле хранит текст само. |
| onChange | `(value: string) => void` | — | Новое значение при вводе. |
| placeholder | `string` | — | Текст-пример в пустом поле. |
| help | `string` | — | Подсказка под полем. |
| error | `string` | — | Ошибка под полем; заменяет подсказку, рамка `danger`. |
| rows | `number` | `3` | Высота в строках. |
| maxLength | `number` | — | Предел символов; включает счётчик «n / max». |
| required | `boolean` | `false` | Пометка «· обязательно» в подписи и `aria-required`. |
| readOnly | `boolean` | `false` | Только чтение: текст виден, фокус остаётся (отправка в `CommentForm`); вид поля не меняется. |
| onKeyDown | `(e) => void` | — | Клавиши в поле: выбор из подсказки (`CommentForm`). |
| combobox | `{ listId, expanded, activeId? }` | — | Поле с подсказкой-списком: `role="combobox"`, `aria-controls`, `aria-expanded`, `aria-activedescendant`. |
| disabled | `boolean` | `false` | Недоступное поле: фон `bg-2`, текст `mute`. |

## Правила
- Вид как у `Input`: подпись 12px `ink-2`, рамка `line-3` (3:1), фокус — рамка `accent` и кольцо `accent-soft`.
- Ошибка — рамка `danger`, текст `danger-ink`, `role=alert`; формулировка говорит, что сделать: «Укажите причину».
- Цвет только у ошибки; подсказка и счётчик — `mute`.
- Поле растягивается по вертикали; в недоступном состоянии растягивание выключено.
- Поле связано с подсказкой или ошибкой и со счётчиком через `aria-describedby`.

## Пример
```tsx
import { Textarea } from "../index";

<Textarea
  id="reason"
  label="Причина возврата"
  required
  maxLength={500}
  help="Задача вернётся в Code; причина попадёт в журнал задачи."
  value={reason}
  onChange={setReason}
  error={submitted && !reason.trim() ? "Укажите причину" : undefined}
/>
```
