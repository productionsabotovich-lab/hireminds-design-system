# H2

Заголовок секции на display-шрифте: section 15px для шапок секций и hero 38px для крупных блоков.

## Когда использовать
- section: заголовки секций настроек workspace («Профиль workspace») и секций BYOK («Провайдер», «API key», «Бюджет и лимиты»).
- hero: крупный заголовок пустого дашборда («Найми первого агента.»), когда полная связка StageHeader не нужна.
- Заголовок страницы — H1, подзаголовок внутри секции — H3. Строковый `header` у Card уже рисует свой заголовок 13.5px.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| size | `"section" \| "hero"` | `"section"` | 15px / 38px. |
| children | `ReactNode` | обязательный | Текст; `<em>` выделяется цветом. |

## Правила
- Всегда `font-display`, вес 600, цвет `ink`; никогда `font-ui`.
- section: 15px, letter-spacing -0.015em, line-height 1.2. hero: 38px, -0.035em, 1.04.
- `<em>` без курсива, цвет `accent-ink`.
- H2 бывает либо шапкой секции, либо hero: не используй его как промежуточный размер между H1 и текстом.

## Пример
```tsx
import { H2 } from "../index";

<H2>Профиль workspace</H2>
<H2 size="hero">Найми первого <em>агента</em>.</H2>
```
