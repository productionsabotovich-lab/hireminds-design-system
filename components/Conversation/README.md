# Conversation

Беседа решения (ADR-0016): участники, плоский список сообщений с ответом цитатой, системные строки по центру и форма с подсказкой по адресату.

## Когда использовать
- «Страница решения»: беседа с ролями и владельцем — «План кампании — беседа с @PM», «Архитектурное решение — спор ролей, итог PM», «Согласовать объём…», «Влить PR — пустая беседа».
- Комментарий под журналом карточки задачи — `CommentForm` с `divider={false}`, без беседы.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| author | `string` | — | Автор решения: «Ответит автор решения — Reviewer», если адресата нет. |
| messages | `({ id, who, human?, time, text, replyTo? } \| { id, system: true, actor?, actorHuman?, text, link?, time })[]` | — | Сообщения и системные события по порядку. |
| mentions | `{ name, kind: "role" \| "person" }[]` | `[]` | Кого можно позвать через «@»; `role` — агент. |
| directory | `Record<string, PersonInfo>` | — | Карточки участников `PersonRef`; `dative` — «В ответ Архитектору». |
| session | `{ label, href }` | — | «Сессия PM →» в шапке: подробности — в сессии роли. |
| onVersion | `() => void` | — | «ред. 3» в системной строке: показать текущую версию содержимого. |
| onSend | `(text, replyTo?) => void \| Promise` | — | Отправка; `replyTo` — id сообщения, на которое отвечают. |
| queue | `ReactNode` | — | Над полем: `MessageQueue`. |
| id | `string` | `"conversation"` | id поля формы. |
| defaultReplyTo | `string` | — | Ответ цитатой открыт сразу (состояние макета). |

## Правила
- Шапка: «Беседа» и аватары тех, кто написал или позван через `@`, — `PersonRef` с карточкой; в пустой беседе аватаров нет.
- Сообщение: аватар (человек — круглый, агент — квадратный), имя — `PersonRef`, «агент» или «человек», время, текст; `@Имя` выделено `accent-ink` и открывает карточку участника.
- Список плоский: ответ — цитатой над текстом, одна строка с многоточием и линией слева; клик прокручивает к исходному сообщению и подсвечивает его на секунду (`accent-soft`).
- «Ответить» — по наведению на сообщение и по фокусу; над полем — полоса «В ответ Архитектору: «…»» с ×.
- Системное событие — разделитель по центру: линии `line` не короче 16px, аватар участника, текст и время через «·»; «ред. 3» — ссылка на текущую версию.
- Подсказка под полем — по адресату: ответ цитатой агенту — «Ответит Архитектор в конце текущего шага»; есть агент — «Агент ответит в конце текущего шага»; только люди — «Участник получит уведомление»; адресата нет — «Ответит автор решения — Reviewer».
- Форма — `CommentForm` `divider={false}`: одна форма на трёх экранах с одинаковыми полем, рамкой и отступами.

## Пример
```tsx
<Conversation
  author="Маркетинг"
  messages={messages}
  mentions={[{ name: "PM", kind: "role" }, { name: "Антон Саботович", kind: "person" }]}
  directory={{ "Антон Саботович": { human: true, dative: "Антону Саботовичу" }, PM: { dative: "PM" } }}
  session={{ label: "Сессия PM", href: "/sessions/S-130" }}
  onSend={(text, replyTo) => api.post({ text, replyTo })}
/>
```
