# EmptyState

Пустое состояние на месте списка или таблицы: пунктирная рамка, короткий заголовок и следующий шаг.

## Когда использовать
- Список пуст: «Запусков нет. Назначьте issue на агента в Linear», «Проектов нет. Подключите проект командой `hm project apply`».
- `variant="mini"` — пустой блок внутри карточки или сайдбара одной строкой: «Решений нет», «Job нет».
- Не для загрузки (это Spinner) и не для ошибки (это Plate `error`). Если данные есть хотя бы частично — EmptyState не нужен.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| variant | `"mini" \| "block"` | `"block"` | mini — одна строка 11.5px; block — заголовок, текст, действие. |
| title | `string` | — | Заголовок, только для block: состояние одной именной группой. |
| children | `ReactNode` | обязательный | Что сделать дальше; команду оборачивай в `<code>`. |
| action | `ReactNode` | — | Следующий шаг (Button, ExternalLink), только для block. |

## Правила
- Рамка `1px dashed line-2`, без заливки — только на фоне `bg`, `bg-2` или `surface`, не на цветном.
- block: паддинг `space-12` `space-6`, радиус `r-lg`, заголовок `font-display` 15px `ink`, текст 13px `mute` (6:1).
- mini: паддинг `space-3`, радиус `r-md`, 11.5px `mute`.
- Текст — что сделать, а не «здесь ничего нет»: если действие в интерфейсе есть, дай `action`; если оно вне интерфейса (CLI, Linear) — назови его в тексте.

## Пример
```tsx
import { EmptyState } from "../index";

<EmptyState title="Проектов нет">Подключите проект командой <code>hm project apply</code>.</EmptyState>
<EmptyState variant="mini">Решений нет</EmptyState>
```
