# ResultReport

«Что сделано»: отчёт агента под решение, собранный из блоков содержимого — текст, списки, таблица, схема, график и вложения-артефакты.

## Когда использовать
- «Страница решения»: что агент сделал и что предлагает (объём, план кампании, архитектурное решение, PR).
- Отчёт роли внутри `PhaseResult` — с `bare`.
- Свёрнутая сводка в карточке задачи — `clamp`.
- **Ничего не предполагает, что решение про код.** Блоки одинаковые для документа, плана кампании, макетов, бюджета, архитектуры и PR; код — только вложением `artifact` (`pr`, `files`, `checks`).

### Блоки
| Блок | Поля | Что рисует |
|---|---|---|
| `text` | `text` | Абзац `Body`. |
| `list` | `title?`, `items` | Подпись моно и маркированный список. |
| `callout` | `tone?` (`info` / `warn`), `title`, `text?` или `items?` | `Plate` с заголовком; `items` — нумерованные шаги. |
| `link` | `label`, `href` | `ExternalLink` action, новая вкладка. |
| `findings` | `title?`, `items: { tone: error / warn / ok / info, text }` | Выводы с точкой тона; тон для читалки — словами. |
| `compare` | `before`, `after` | «Было → стало» — `DescriptionList` в две колонки. |
| `artifact` | `artifact` | Вложение через `ArtifactView` — где уместно по тексту, сколько угодно раз. |
| `table` | `title?`, `columns: { label, num? }`, `rows: { cells, total?, pick? }` | `Table` dense: первая ячейка — заголовок строки, `num` — числа справа, итоговая строка, строка-рекомендация. |
| `diagram` | `label`, `caption?`, `nodes: { id, label, x, y, accent? }`, `edges: [from, to, label?]`, `width?`, `height?`, `nodeWidth?` | Схема SVG: узлы и стрелки на токенах, до 600px. |
| `chart` | `label`, `caption?`, `x`, `series: { label, tone?, values }`, `max?`, `ticks?`, `unit?`, `xLabel?` | Линейный график: одна шкала, подписи осей, легенда тонами, до 600px. |

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| blocks | `ReportBlock[]` | — | Блоки по порядку (таблица выше). |
| title | `string` | «Что сделано» | Заголовок карточки. |
| caption | `string` | — | Подпись у заголовка: «Архитектор · 12 мин назад». |
| bare | `boolean` | `false` | Без рамки и заголовка — внутри другой карточки. |
| clamp | `boolean` | `false` | Свёрнуто: первый абзац на 3 строки и «Показать результат полностью». |
| fullHref | `string` | — | `clamp`: «Показать результат полностью» — ссылкой сюда, а не раскрытием на месте. |
| interim | `boolean` | `false` | Промежуточный результат: только `Pill` «промежуточный» у заголовка. |

## Правила
- Своей вёрстки содержимого нет: блоки — примитивы системы (`Body`, `Plate`, `DescriptionList`, `Table`, `ArtifactView`).
- Цвета схемы и серий графика — только токены: узел `surface` / `line-3`, выделенный — `accent-soft` / `accent`; серии `accent`, `warn-2` (3:1 на `surface`), `ink-3`; сетка `line`, подписи `mute` 10.5px.
- Схема и график не крупнее текста страницы: до 600px; уже своей ширины (375px) не сжимаются, а прокручиваются в рамке — подписи остаются 10.5–12px; `label` — описание для читалки (`role="img"`).
- Таблица сравнения от 4 колонок на 375px прокручивается в своей рамке с тенью у правого края.

## Пример
```tsx
<ResultReport
  caption="Архитектор · 12 мин назад"
  blocks={[
    { type: "text", text: "Предлагаю очередь задач на Postgres." },
    { type: "table", title: "Сравнение", columns: [{ label: "Вариант" }, { label: "Задержка, мс", num: true }], rows: [{ cells: ["Postgres", "120"], pick: true }] },
    { type: "artifact", artifact: { type: "doc", path: "docs/adr/0021-queue.md", href: "/docs/0021" } },
  ]}
/>
```
