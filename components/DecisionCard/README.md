# DecisionCard

Открытое решение в закреплённой зоне над журналом карточки задачи: решение и гейт, «Ждёт решения», строка ожидания и «Открыть решение».

## Когда использовать
- «Карточка задачи», состояние «Ждёт решения: лимит возвратов исчерпан» — первым в `PinnedZone`, выше идущей сессии.
- Список решений — `List` и `ListItem` (композиция «Решения» в README `List`).

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| id | `string` | — | Решение — `EntityRef` `decision`: «D-44». |
| gate | `string` | — | Гейт — `H3` inline: «Лимит возвратов исчерпан». |
| line | `string` | — | Строка ожидания `mute` в одну строку с многоточием: «Ждёт Антона Саботовича 23 ч 45 мин». |
| onOpen | `() => void` | — | «Открыть решение» — страница решения. |

## Правила
- «Ждёт решения» — `Pill` `warn` с точкой и пульсом; кнопка — `primary` sm, справа; на узкой ширине уходит под текст.
- Карточка — `surface`, рамка `line`, `r-lg`, тень `sh-1`.

## Пример
```tsx
<DecisionCard id="D-44" gate="Лимит возвратов исчерпан" line="Ждёт Антона Саботовича 23 ч 45 мин" onOpen={() => router.push("/decisions/D-44")} />
```
