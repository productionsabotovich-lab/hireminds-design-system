# TaskSummary

Задача из трекера одинаково на всех экранах: карточка в боковой колонке, «О задаче», строка списка, всплывающая карточка, описание над вкладками.

## Когда использовать
- Везде, где экран показывает задачу трекера: боковая колонка сессии, страница решения, карточка задачи, списки и очередь, всплывающая карточка по наведению на ключ.
- Вариант выбирается пресетом (`preset`); отдельные свойства включаются и выключаются через `fields`.
- Только ссылка на задачу в тексте или строке — `EntityRef` `kind="task"`; список чего-то другого — `List` и `ListItem`.
- Раннер и тип задачи здесь не показываются: раннер — свойство агента, тип дублирует метки. Ветка — в PR и шапках групп файлов.

### Вариант → свойства → место
| Вариант | Свойства | Место |
|---|---|---|
| `full` | сетка «подпись — значение» с иконками: статус в трекере, состояние, приоритет, эпик, цель, исполнитель, фаза с причиной, метки, цикл, срок, заведена, обновлено | «О задаче» в карточке задачи |
| `side` | заголовок; строка метаданных: состояние, приоритет, эпик; строка фазы с причиной; описание 2 строки; «Открыть карточку задачи» | боковая колонка сессии |
| `decision` | заголовок; строка метаданных: состояние, фаза, приоритет; «Открыть карточку задачи» | страница решения |
| `popover` | заголовок; состояние; исполнитель; строка фазы; описание 2 строки; ширина 320px | всплывающая карточка по наведению на задачу |
| `row` | строка `ListItem`: ключ и название; справа исполнитель, состояние, приоритет | список задач (внутри `List`) |
| `queue` | строка `ListItem`: ключ и название; справа приоритет и место в очереди | очередь (внутри `List`) |
| `description` | только описание, 3 строки; пустое — «Описание в Linear не заполнено» | основная колонка карточки задачи над вкладками |

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| task | `TaskSummaryTask` | — | Данные задачи: `key`, `title`, `href`, `tracker`, `state { label, tone, pulse? }`, `status`, `priority`, `epic`, `goal`, `assignee { name, human?, image? }`, `phase`, `labels`, `cycle`, `due`, `created`, `updated`, `queuePosition`, `description`. Пустые поля не рисуются. |
| preset | `"full" \| "side" \| "decision" \| "row" \| "popover" \| "queue" \| "description"` | `"side"` | Готовый набор свойств (таблица выше; объект — `TASK_SUMMARY_PRESETS`). |
| fields | `Partial<TaskSummaryFields>` | — | Поправки к набору: `status`, `priority`, `epic`, `assignee`, `phase` (`true` — строкой, `"inline"` — в строке метаданных), `description` (`0 \| 2 \| 3` строки), `labels`, `trackerStatus`, `updated`, `details`, `openLink`, `queuePosition`; `density`, `form`. |
| reason | `string` | — | Причина запуска фазы: «Продолжена после возврата из QA» — рядом с бейджем фазы, с маленькой буквы. |
| cardHref | `string` | — | Карточка задачи у нас — для «Открыть карточку задачи» (`side`, `decision`). |
| compact | `boolean` | `false` | `row`, `queue`: строка 32px. |
| defaultOpen | `boolean` | `false` | Описание сразу раскрыто. |

`description` — строка (один абзац) или блоки: `{ type: "p", text }`, `{ type: "h", text }`, `{ type: "list", ordered?, items }`, `{ type: "code", text }`, `{ type: "images", items: [{ src, alt, href? }] }`. Текст абзаца и пункта — строка или куски: строка, `{ text, href }` (`ExternalLink` inline, новая вкладка), `{ code }` (`CodeChip` sm).

## Правила
- Строка метаданных — без «·» и без переноса, элементы через `space-3`. При нехватке места (карточка до 360px) подпись приоритета сворачивается до иконки с подсказкой «Приоритет: высокий»; фаза и эпик обрезаются многоточием.
- Фаза — `Pill` тона `ink` без иконки, полное название — в подсказке браузера.
- Приоритет — иконка цветом (`danger`, `warn-2`, `ink-2`, `mute`) и подпись; `warn` на белом ниже 3:1 для иконки.
- Заголовок — `EntityRef` `size="title"`: ключ, название в одну строку и ↗; полное название — в подсказке, если обрезано (в `full` — всегда, с «Открыть в Linear»).
- `full` — `DescriptionList` `layout="row"`: подпись 128px с иконкой, значение в одну строку.
- Описание свёрнуто до 3 строк (в `side` и `popover` — до 2); «Показать полностью» появляется, только если текст не поместился.
- `row` и `queue` — только внутри `List`: колонки справа постоянной ширины во всех строках; в узком списке (до 360px) справа только аватар исполнителя (`ListItem` `trailingNarrow`, по макету 375px), состояние — точкой с подписью во второй строке, приоритет и место в очереди скрыты.
- `List` выравнивает иконки только прямых `ListItem`: строки `TaskSummary` в одном списке со строками, у которых есть `leading`, не смешивай.

## Пример
```tsx
<TaskSummary
  preset="side"
  task={{
    key: "PIL-15",
    title: "Роли участников проекта: owner, admin и viewer",
    href: "https://linear.app/…/PIL-15",
    tracker: "Linear",
    state: { label: "В работе", tone: "accent", pulse: true },
    priority: "high",
    epic: { name: "Доступ и роли" },
    phase: "Code",
    description: "Нужны три роли участника проекта…",
  }}
  reason="Продолжена после возврата из QA"
  cardHref="/tasks/PIL-15"
/>

<List title="Задачи" count={2}>
  <TaskSummary preset="row" task={pil15} />
  <TaskSummary preset="row" task={pil22} />
</List>
```
