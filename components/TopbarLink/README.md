# TopbarLink

Ссылка правого слота `Topbar` перед аватаром: иконка, подпись и счётчик; `attention` — точка у иконки и число для «Моих решений»; `soon` — пункт, которого ещё нет.

## Когда использовать
- Шапка всех экранов webapp (композиция TopBar — в README `Topbar`): «Мои решения» с `tone="attention"`, «Файлы» — `soon`.
- Счётчик считает решения, которые ждут текущего человека, а не задачи.
- Пункт боковой навигации — не здесь, а `NavLink`.

### Граница с NavLink
| TopbarLink | NavLink |
|---|---|
| правый слот `Topbar`, в строку | боковая навигация, в столбец |
| счётчик, точка внимания или «скоро» | иконка и подпись, активный пункт |
| плашка с рамкой `line`; текущая страница — заливка `inset` | активный пункт — мягкий `accent` |

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| href | `string` | — | Адрес; обязателен у активной ссылки, у `soon` не задаётся. |
| label | `string` | — | Подпись: «Мои решения», «Файлы». |
| shortLabel | `string` | — | Подпись на экране до 600px: «Решения». |
| icon | `IconName` | — | Иконка из `Icon`, 14px; в макете — только у «Мои решения». |
| badge | `{ kind: "count", value }` или `{ kind: "soon" }` | — | Счётчик решений или пункт, которого ещё нет. |
| tone | `"default" \| "attention"` | `"default"` | `attention`: зелёная точка у иконки, пока `value` > 0; число — обычным текстом после подписи; ноль — ни точки, ни числа. |
| unseen | `number` | `0` | `attention`: сколько решений ещё не открывали — точка пульсирует. |
| current | `boolean` | `false` | Текущая страница: `aria-current="page"` и заливка `inset`. |

## Правила
- `default`: счётчик больше 0 — заливка `ink` и белый текст; 0 — `inset` и `mute`; больше 99 — «99+».
- `attention`: точка `accent` у правого верхнего края иконки входящих; пульсирует, пока есть неоткрытые (`unseen` > 0), иначе — без пульса; число моноширинным `ink-2` после подписи. Пульс выключается при `prefers-reduced-motion`.
- Для диктора ссылка читается целиком: «Мои решения: 4 открыто, из них 2 новых»; точка и число скрыты.
- Вид — плашка 28px с рамкой `line` на `surface`; наведение — рамка `line-2`; текущая страница — фон и рамка `inset`; фокус с клавиатуры — кольцо `accent`.
- `soon` — без рамки и фона, подпись `mute`, не ссылка и в порядок фокуса не входит; без метки, подсказка «Скоро» по наведению, для диктора — «Файлы, скоро». «Итерация N» в интерфейсе не пишется; `badge.value` не показывается.
- До 600px показывается `shortLabel` — задавай его, если подпись длиннее одного слова. До 400px пункты `soon` скрыты: на экране 320px шапке не хватает места для «Мои решения» и аватара.

## Пример
```tsx
<TopbarLink label="Файлы" badge={{ kind: "soon" }} />
<TopbarLink href="/decisions" label="Мои решения" shortLabel="Решения" icon="inbox" tone="attention" badge={{ kind: "count", value: 4 }} unseen={2} />
```
