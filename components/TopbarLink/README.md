# TopbarLink

Ссылка правого слота `Topbar` перед аватаром: иконка, подпись и бейдж — счётчик открытых решений или пометка «итерация 3» у неактивной ссылки.

## Когда использовать
- Шапка всех экранов webapp: «Мои решения» со счётчиком, «Моя команда» и «Журнал» до итерации 3.
- Счётчик считает решения, которые ждут текущего человека, а не задачи.
- Пункт боковой навигации — не здесь, а `NavLink`.

### Граница с NavLink
| TopbarLink | NavLink |
|---|---|
| правый слот `Topbar`, в строку | боковая навигация, в столбец |
| бейдж-счётчик или пометка итерации | иконка и подпись, активный пункт |
| плашка с рамкой `line`; текущая страница — заливка `inset` | активный пункт — мягкий `accent` |

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| href | `string` | — | Адрес; обязателен у активной ссылки, у ссылки с бейджем `soon` не задаётся. |
| label | `string` | — | Подпись: «Мои решения», «Моя команда», «Журнал». |
| shortLabel | `string` | — | Подпись на экране до 600px: «Решения». |
| icon | `IconName` | — | Иконка из `Icon`, 14px; в макете — только у «Мои решения». |
| badge | `{ kind: "count", value }` или `{ kind: "soon", value? }` | — | Счётчик решений или пометка «итерация 3»; `soon` делает ссылку неактивной. |
| current | `boolean` | `false` | Текущая страница: `aria-current="page"` и заливка `inset`. |

## Правила
- Счётчик больше 0 — заливка `ink` и белый текст; 0 — `inset` и `mute`; больше 99 — «99+». Не `accent`: умеренный монохром.
- Для диктора ссылка со счётчиком читается целиком: «Мои решения: 4 открыто»; сам бейдж скрыт.
- Вид — плашка 28px с рамкой `line` на `surface`; наведение — рамка `line-2`; текущая страница — фон и рамка `inset`; фокус с клавиатуры — кольцо `accent`.
- Неактивная ссылка `soon` — без рамки и фона, подпись `dim`, `role="link"` и `aria-disabled`, в порядок фокуса не входит; пометка «итерация 3» на `inset`. Иконку ей не ставь.
- На экране до 720px ссылки `soon` скрыты, чтобы «Мои решения» и аватар оставались в шапке; до 600px показывается `shortLabel` — задавай его, если подпись длиннее одного слова.

## Пример
```tsx
import { Brand, Topbar, TopbarLink, UserAvatar } from "../index";

<Topbar
  left={<Brand />}
  right={
    <>
      <TopbarLink label="Моя команда" badge={{ kind: "soon" }} />
      <TopbarLink href="/decisions" label="Мои решения" shortLabel="Решения" icon="inbox" badge={{ kind: "count", value: 4 }} />
      <UserAvatar name="Антон Саботович" size="sm" shape="circle" />
    </>
  }
/>
```
