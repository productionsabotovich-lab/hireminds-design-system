# Stack

Вертикальная раскладка: дети в колонку с отступом из шкалы `space-*`.

## Когда использовать
- Страница из секций: шапка, сводка, таблицы — `Stack gap={6}`; внутри секции заголовок и таблица — `gap={3}`.
- Заголовок с подзаголовком — `gap={2}`.
- Элементы в строку — Cluster. Сетка колонок — пока локальный grid экрана.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| gap | `SpaceStep` (1–17) | `4` | Отступ между детьми: шаг шкалы, `4` → `space-4` (16px). |
| align | `"stretch" \| "start" \| "center" \| "end"` | `"stretch"` | Выравнивание по горизонтали. |
| as | `"div" \| "section" \| "main" \| "ul" \| "ol"` | `"div"` | HTML-элемент. |
| children | `ReactNode` | обязательный | Содержимое. |
| className | `string` | — | Дополнительный класс (ширина, паддинги страницы). |

## Правила
- Отступы между блоками задаёт только Stack: у детей не должно быть внешних `margin`.
- Ритм страницы: секции `space-6`, заголовок и его содержимое `space-3`, заголовок и подзаголовок `space-2`.
- Дети получают `min-width: 0`, поэтому таблицы и длинный текст не распирают колонку.
- Список с `as="ul"` идёт без маркеров и отступов.

## Пример
```tsx
import { Stack, SectionHeader, Table } from "../index";

<Stack as="main" gap={6}>
  <Stack as="section" gap={3}>
    <SectionHeader count={5}>Запуски</SectionHeader>
    <Table columns={columns} rows={rows} />
  </Stack>
</Stack>
```
