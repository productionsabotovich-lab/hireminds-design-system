# PinnedZone

Закреплённая зона над журналом карточки задачи: то, что ждёт действия или идёт сейчас — решение выше идущей сессии; при прокрутке остаётся под шапкой.

## Когда использовать
- «Карточка задачи»: `DecisionCard` открытого решения, затем `SessionLive` `widget` идущей сессии.
- Нечего закреплять — зона не рисуется (возвращает `null`).

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| children | `ReactNode` | — | По порядку: решение выше сессии. |
| label | `string` | «Сейчас по задаче» | Имя зоны для читалки (`role="region"`). |
| top | `number` | `52` | Отступ сверху при прокрутке, px: высота шапки сайта (`Topbar` 50px и зазор); плюс safe-area телефона. |

## Правила
- `position: sticky` под шапкой; фон `bg` закрывает журнал, который уходит под зону; между элементами — `space-2`.
- Sticky работает, только если зона — прямой потомок прокручиваемой колонки (или её содержимого без своего `overflow`): обёртка с `overflow: hidden` между ними закрепление отключает.
- Виджет сессии в зоне — во всю ширину.

## Пример
```tsx
<PinnedZone>
  <DecisionCard id="D-44" gate="Лимит возвратов исчерпан" line="Ждёт 23 ч 45 мин" href="/decisions/D-44" />
  <SessionLive role="Developer" sessionId="S-118" href="/sessions/S-118" elapsed="25 мин" plan={{ done: 3, total: 6 }} operation="ждёт решения" />
</PinnedZone>
```
