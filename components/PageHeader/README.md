# PageHeader

Шапка экрана сущности — задачи, сессии, решения: «←» назад, `EntityRef` heading, фаза и состояние, главные действия; ниже — мелкая приглушённая строка.

## Когда использовать
- Шапки «Карточки задачи», «Сессии агента», «Страницы решения» во всех состояниях — одна шапка, одни кегли и отступы.
- Шапка сайта (логотип, крошки, «Мои решения») — композиция TopBar, см. README `Topbar`.
- Заголовок раздела внутри страницы — `SectionHeader`.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| back | `{ href, label }` | — | «←» — `BackLink` `variant="icon"`; `label` — подсказка и имя для читалки: «К задаче PIL-15». |
| entity | `{ kind, id, title?, href?, newTab?, hint? }` | — | Сущность — `EntityRef` `size="heading"` в `H1` `section`. |
| phase | `string` | — | Фаза — `Pill` `ink`, первой в группе бейджей. |
| state | `{ label, tone, pulse? }` | — | Состояние — `Pill` с точкой после фазы. |
| meta | `string[]` | — | Строка 2: мелкий `mute` текст через «·»; пустые значения пропускаются; нет содержимого — строки нет. |
| actions | `ReactNode` | — | Главные действия справа по строке заголовка: `Button`. |

## Правила
- Строка 1: [«←»] иконка сущности, ключ, название, [↗] · фаза и состояние плотной группой (`space-2`) · справа действия.
- Строка 2 — только мелкий приглушённый текст (`caption-ui`, `mute`) через «·», в `space-1` под заголовком. Исполнителей в шапке нет — они в правой колонке; проект и эпик — в крошках TopBar.
- Шапка шире 600px: «←» висит слева от края контента (иконка сущности — на одной вертикали с блоками ниже). Чтобы «←» не выходила за поле страницы, у колонки контента слева должно быть поле не меньше 36px (28px «←» + `space-2`). Шапка уже 600px — «←» в строке, перед заголовком.
- Ширина — по родителю (`width: 100%`): шапка — контейнер, порог 600px считается по её ширине.

## Пример
```tsx
<PageHeader
  back={{ href: "/tasks/PIL-15", label: "К задаче PIL-15" }}
  entity={{ kind: "decision", id: "D-46", title: "Утверждение плана кампании" }}
  phase="Утверждение"
  state={{ label: "Ждёт решения", tone: "warn" }}
  meta={["ждёт Антона Саботовича 40 мин", "напоминание сегодня 17:32"]}
  actions={<Button size="sm">Утвердить</Button>}
/>
```
