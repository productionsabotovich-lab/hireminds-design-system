# Body

Нейтральный абзац для описаний внутри карточек, шагов и trust-блоков: 13.5px или 12px, по умолчанию цвета mute.

## Когда использовать
- `size="small"`: описания шагов в checklist дашборда и в таймлайне aside на forgot-password.
- Пояснения в sidebar (пустой список AI-команды), статус «Готово к повторной отправке» на email-sent.
- `tone="ink-3"`: trust-текст под API-ключом на BYOK; `tone="ink"`: имя пользователя в футере sidebar.
- Сразу под H1 ставь Lead, подсказку под полем Help, мелкую mono-мету Caption.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| tone | `"mute" \| "ink" \| "ink-2" \| "ink-3"` | `"mute"` | Цвет текста. |
| size | `"base" \| "small"` | `"base"` | base: 13.5px / line-height 1.48; small: 12px / 1.5. |
| className | `string` | — | Дополнительный класс на `<p>`. |
| children | `ReactNode` | обязательный | Текст. |

## Правила
- Шрифт `font-ui`, вес 400, margin 0: отступы задаёт родитель через gap на шкале `space-*`.
- По умолчанию `mute`; `ink-3` для значимых микро-абзацев (trust), `ink` только для выделения имени.
- Не ставь вес 500 и не увеличивай до 14px цвета `ink`: это уже лейбл или Lead.
- Не верстай `<p style={{ fontSize: 13 }}>` в страницах, используй Body.

## Пример
```tsx
import { Body } from "../index";

<Body size="small">Письмо придёт в течение 1–2 минут. Проверь «Спам».</Body>
<Body size="small" tone="ink-3">Где живёт ваш ключ — только у вас.</Body>
```
