# Tooltip

Подсказка к значку или короткому элементу без подписи: открывается по наведению и по фокусу с клавиатуры, текст доступен читалке экрана.

## Когда использовать
- Значок без подписи: приоритет иконкой в строке задачи («Приоритет: высокий»), ↗ «Открыть карточку агента», «Ответить» в беседе.
- Ссылка-иконка «←» в шапке экрана — `BackLink` `variant="icon"` уже включает подсказку.
- Не для важного: то, без чего нельзя принять решение, пишется текстом на экране. На телефоне наведения нет — подсказка видна только по фокусу.
- Не для длинного текста и не для интерактива внутри: ссылки и кнопки в подсказке не нажать — для карточки участника есть свой компонент.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| text | `string` | обязательный | Текст подсказки, коротко: «Приоритет: высокий». |
| children | `ReactNode` | обязательный | Элемент, к которому подсказка. |
| focusable | `boolean` | `true` | `true` — обёртка сама в порядке Tab (значок без своего фокуса) и получает `aria-describedby`. `false` — фокус у вложенной ссылки или кнопки, `aria-describedby` добавляется ей. |

## Правила
- Открывается по наведению и по фокусу; закрывается по Esc, уходу курсора и потере фокуса.
- Пузырь над элементом по центру: фон `ink`, текст `surface` (18:1), `font-ui` 11.5px, паддинг `space-1` `space-2`, радиус `r-sm`, зазор `space-1`. Длинный текст переносится, не шире 280px.
- Не выходит за край экрана: у левого и правого края сдвигается внутрь с отступом 8px, у верхнего — открывается под элементом.
- Для читалки — `role="tooltip"` и `aria-describedby` на элементе в фокусе: подсказка читается после его названия.
- Фокус обёртки (`focusable`) — кольцо `accent`. Появление без анимации при `prefers-reduced-motion`.
- Внутри `overflow: hidden` подсказку обрежет родитель: ставь её вне таких контейнеров или открывай им `overflow` при наведении.

## Пример
```tsx
import { Icon, Tooltip } from "../index";

<Tooltip text="Приоритет: высокий">
  <Icon name="priority" size={16} />
</Tooltip>

<Tooltip text="Открыть карточку агента" focusable={false}>
  <a href="/agents/developer" aria-label="Открыть карточку агента Developer">↗</a>
</Tooltip>
```
