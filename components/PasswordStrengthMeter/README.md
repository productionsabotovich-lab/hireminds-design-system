# PasswordStrengthMeter

Индикатор надёжности пароля: полоса из 4 сегментов с оценкой и чеклист правил, с необязательной проверкой утечек.

## Когда использовать
- Под полем нового пароля при регистрации (create-account) и на reset-password, вместе с `checkLeaked`.
- Не на форме входа: там пароль уже существует и оценивать его незачем.
- Не для PIN и кодов; в узких колонках вроде sidebar не помещается, нужна ширина от 240px.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| password | `string` | обязательный | Текущее значение; при пустой строке компонент ничего не выводит. |
| checkLeaked | `boolean` | `false` | Проверка по базе HaveIBeenPwned через k-anonymity, с задержкой 600ms, от 8 символов. |
| onLeakedChange | `(leaked: boolean) => void` | — | Результат проверки утечки. |
| onScoreChange | `(score: number) => void` | — | Оценка 0–4 при каждом изменении; по ней блокируй submit. |
| className | `string` | — | Дополнительный класс на корень. |

## Правила
- Сегменты высотой 3px, gap 4px, радиус 2px. Пустые `inset`; заполненные при оценке 0–1 `danger`, при 2 `warn`, при 3–4 `accent`.
- Строка под полосой: `font-mono` 10.5px, letter-spacing 0.04em, цвет `mute`; слева «надёжность пароля», справа оценка («слабый», «хороший · ~N лет») цветом полосы, с оценки 3 вес 600.
- Чеклист: сетка в 2 колонки, фон `bg-2`, рамка `line`, радиус 7px, паддинг 13px 14px; правила «8+ символов», «хотя бы 1 цифра», «хотя бы 1 заглавная», «не из leaked-списка». Выполненный пункт `accent-ink`, чекбокс 14px на `accent`.
- Оценка не поднимается выше 2, пока не выполнены длина, цифра и заглавная: не дублируй эту логику в форме, бери `onScoreChange`.
- Не заменяй цвета HEX-оттенками и не добавляй своих правил в чеклист.

## Пример
```tsx
import { PasswordStrengthMeter } from "../index";

<PasswordStrengthMeter password={password} checkLeaked onScoreChange={setScore} />
```
