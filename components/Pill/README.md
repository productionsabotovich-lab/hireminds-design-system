# Pill

Бейдж состояния: короткий текст на мягкой заливке своей цветовой семьи, с точкой-ореолом по желанию; тон `ink` — название фазы в журнале.

## Когда использовать
- Состояние задачи, решения или сессии: «В работе», «Ждёт решения», «Ошибка», «Остановлено».
- Название фазы в строке перехода журнала («Code → Review») — тон `ink`.
- Статус рядом с заголовком страницы (`size="md"`): «Workspace ready», «Подключён».
- Подробности состояния (причина блокера, чьё решение ждём) выводи текстом рядом с Pill, не внутри: Pill — одно слово или именная группа.
- Не для действий (Pill не кликабелен), не для длинных сообщений (это Plate), не для счётчиков.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| tone | `"accent" \| "warn" \| "danger" \| "dim" \| "ink"` | `"dim"` | Семья цвета; `ink` — сплошная заливка для названия фазы. |
| size | `"sm" \| "md"` | `"sm"` | sm — 20px, `font-ui` 11.5px; md — 24px, `font-mono` 10.5px uppercase. |
| dot | `boolean` | `false` | Точка-ореол перед текстом. |
| pulse | `boolean` | `false` | Пульсация точки для живого процесса; отключается при `prefers-reduced-motion`. |
| children | `ReactNode` | обязательный | Текст состояния. |

## Правила
- Тоны: accent — фон `accent-soft`, текст `accent-ink`; warn — `warn-soft` и `warn-ink`; danger — `danger-soft` и `danger-ink`; dim — `inset` и `mute`; ink — фон `ink`, текст белый (18:1). Все пары проходят AA 4.5:1.

| Состояние | Тон |
|---|---|
| успех, утверждено | `accent` |
| возврат, напоминание, просрочка | `warn` |
| ошибка, лимит | `danger` |
| устарело, остановлено | `dim` |
| живое (идёт сейчас) | тон состояния + `dot` + `pulse` |
| название фазы в строке перехода журнала | `ink` |

- `ink` — не состояние: только фаза («Code», «Review») в строке перехода журнала. Для состояний он не используется — умеренный монохром держится на четырёх мягких тонах.
- Пульсирует только то, что идёт прямо сейчас; в одной строке таблицы — не больше одного Pill.
- Высота sm 20px вместо 17px из макета: текст 11.5px в таблицах должен читаться.

## Пример
```tsx
import { Pill } from "../index";

<Pill tone="accent" dot pulse>Выполняется</Pill>
<Pill tone="danger" dot>Ошибка</Pill>
<Pill tone="ink">Review</Pill>
<Pill tone="dim">Завершён</Pill>
```
