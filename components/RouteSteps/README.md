# RouteSteps

Маршрут задачи в одну строку: шаги равной сеткой, точки на линии и подписи по центру — пройденные, текущий и будущие.

## Когда использовать
- Блок «Маршрут задачи» карточки задачи: где задача сейчас на маршруте проекта. Шаги, их названия и число берутся из
  workflow проекта («Объём → Code → CI → Ревью → QA → Приёмка» — только пример); компонент конкретных шагов не знает.
- Кто сейчас на шаге и что делает — не здесь: это «Сессии ролей» и `SessionLive`.
- Шаги мастера формы (онбординг, сброс пароля) — `StepIndicator`.

### Отличие от StepIndicator
| RouteSteps | StepIndicator |
|---|---|
| маршрут задачи, только показывает | шаги мастера формы, ведут пользователя |
| горизонтально, точки на линии, подпись под точкой | моно-подпись «STEP 1 / 3» и полоса |
| пройденные — `accent`, текущий — живая точка `ink` | текущий шаг — номер |

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| steps | `string[]` | обязательный | Подписи шагов из workflow проекта, по порядку; любое число и любые названия. |
| current | `number` | `0` | Индекс текущего шага; до него — пройденные, после — будущие. |
| done | `boolean` | `false` | Все шаги пройдены: задача принята. |
| live | `boolean` | `true` | Пульс точки текущего шага — задача в работе. Задача ждёт решения или человека — `false`. |

## Правила
- Пройденный шаг — `Dot` `accent` sm (3.3:1) и подпись `mute`; текущий — `Dot` `ink` md, подпись `ink` 600, `aria-current="step"`; будущий — пустая точка с контуром `line-3` (3:1) и подпись `mute` (5.9:1 к `bg`).
- `accent` — только у пройденных точек: умеренный монохром.
- Линия между точками — `line`; она не заходит под точку, поэтому компонент кладётся на `bg`, `surface` и любой другой фон без настройки.
- Подписи короткие; длинная переносится по словам, не больше двух строк, дальше многоточие, полный текст в `title`.
- Колонки равные, не уже 48px и не уже самого длинного слова подписи. Шесть коротких шагов помещаются в боковую колонку 320px
  и на 375px; если шагов больше, чем помещается, строка прокручивается по горизонтали и текущий шаг виден сразу.
- Для экранного чтения у пройденного шага — «пройден», у текущего — «текущий, в работе» или «текущий, ожидает» и `aria-current="step"`.
- Пульс отключается при `prefers-reduced-motion` (как у `Dot`).

## Пример
```tsx
import { RouteSteps } from "../index";

<RouteSteps steps={["Объём", "Code", "CI", "Ревью", "QA", "Приёмка"]} current={1} />
<RouteSteps steps={steps} current={4} live={false} />
<RouteSteps steps={steps} done />
```
