# PhaseResult

Раздел «Результата» задачи по одной фазе workflow: фаза, роль, «из сессии S-118 ↗», отчёт роли и артефакты последней версии; прошлые версии свёрнуты.

## Когда использовать
- «Карточка задачи», состояние «Принята: результат по фазам», и вкладка «Результат» «Сессии агента» — по одному разделу на фазу.
- Роль любая: «Developer», «Безопасность», «Маркетинг», человек на утверждении.
- Фаза, у которой ещё нет результата, — одной строкой состояния (`status`).

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| phase | `string` | — | Фаза — `Pill` `ink`. |
| role, human | `string`, `boolean` | —, `false` | Роль с аватаром: агент — квадратный, человек — круглый. |
| session | `{ id, href? }` | — | «из сессии S-118 ↗». |
| at | `string` | — | Когда: «сегодня, 14:20». |
| status | `"running" \| "error" \| "waiting"` | — | Строка состояния без содержимого: «идёт» (пульс), «ошибка», «ждёт решения». |
| note | `string` | — | Подпись к строке состояния. |
| report | `ReportBlock[]` | — | Отчёт роли — `ResultReport` `bare`. |
| artifacts | `Artifact[]` | — | Артефакты последней версии — `ArtifactView`. |
| earlier | `{ label?, report?, artifacts? }[]` | `[]` | Прошлые версии, новые сначала: свёрнуты строкой «ранее: N версии». |
| earlierNote | `string` | — | Подпись к «ранее»: «— до возврата из QA». |
| openEarlier | `boolean` | `false` | Прошлые версии раскрыты. |

## Правила
- Показывается последняя версия; прошлые — по кнопке «ранее: 2 версии ▾», раскрытые — с линией `line` слева.
- Строка состояния — без тени, на `surface`; «идёт» — `role="status"`.

## Пример
```tsx
<PhaseResult
  phase="Code"
  role="Developer"
  session={{ id: "S-118", href: "/sessions/S-118" }}
  at="сегодня, 14:20"
  report={[{ type: "text", text: "Роли owner, admin и viewer: права проверяются на сервере." }]}
  artifacts={[{ type: "pr", items: [pr18] }]}
  earlier={[{ label: "v1 · вернул QA", report: [{ type: "findings", items: [{ tone: "error", text: "viewer видел «Удалить участника»" }] }] }]}
/>
```
