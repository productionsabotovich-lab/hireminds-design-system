# Switcher

Компактный переключатель из 2–3 вкладок на сером треке; активная вкладка выделена белой плашкой.

## Когда использовать
- Над формой signin: «Sign in / Create account», форма перестраивается по выбранной вкладке.
- Выбор темы Light / Dark / Auto в настройках оформления, выбор периода Monthly / Annual.
- Для 4 и больше вариантов бери select или радиокнопки, для перехода между страницами NavLink, для множественного выбора чипы.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| tabs | `SwitcherTab[]` (`{ id: string; label: string }`) | обязательный | Вкладки. |
| activeId | `string` | обязательный | id активной вкладки; компонент контролируемый. |
| onSelect | `(id: string) => void` | обязательный | Выбор вкладки. |
| className | `string` | — | Дополнительный класс на трек. |

## Правила
- Трек: фон `inset`, радиус `r-md` (6px), паддинг 3px, gap 4px.
- Вкладка: высота 22px, паддинг 0 10px, радиус 4px, `font-ui` 11.5px вес 500, цвет `mute`.
- Активная: фон `surface`, текст `ink`, тень `0 1px 2px rgba(17,20,24,.06)` и кольцо 1px `line`. Активную вкладку не крась в `accent`.
- Подписи в 1–2 слова; не растягивай трек на всю ширину и не увеличивай вкладки до высоты кнопки.
- Switcher только меняет состояние, отправку формы делает кнопка.

## Пример
```tsx
import { Switcher } from "../index";

<Switcher
  tabs={[{ id: "signin", label: "Войти" }, { id: "register", label: "Создать аккаунт" }]}
  activeId={tab}
  onSelect={setTab}
/>
```
