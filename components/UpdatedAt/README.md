# UpdatedAt

Отметка свежести данных: «Обновлено N с назад», пересчитывается каждую секунду, во время запроса — «Обновляется».

## Когда использовать
- Рядом с кнопкой «Обновить» на экранах с автообновлением: список запусков, карточка запуска.
- Время самого события (вход в фазу, создание записи) — не UpdatedAt, а время в формате экрана.

## Пропсы
| Prop | Тип | По умолчанию | Что делает |
|---|---|---|---|
| updatedAt | `number \| Date` | обязательный | Когда пришёл последний ответ сервера. |
| loading | `boolean` | `false` | Запрос идёт: выводит «Обновляется». |

`formatUpdated(updatedAt, now)` экспортируется отдельно — для тестов и серверного рендера.

## Правила
- Тексты: «Обновлено только что» (до 2 с), «Обновлено 5 с назад», «Обновлено 3 мин назад», «Обновлено 2 ч назад», «Обновляется».
- `font-ui` 12px `mute`, табличные цифры, без переноса — ширина не прыгает каждую секунду.
- `role="status"`: экранные дикторы озвучивают смену текста вежливо, не перебивая.
- Время берётся из ответа, а не из нажатия кнопки: при ошибке запроса отметка остаётся старой.

## Пример
```tsx
import { Cluster, UpdatedAt, Button } from "../index";

<Cluster gap={3}>
  <UpdatedAt updatedAt={lastFetchAt} loading={fetching} />
  <Button variant="secondary" size="sm" loading={fetching} onClick={refresh}>Обновить</Button>
</Cluster>
```
